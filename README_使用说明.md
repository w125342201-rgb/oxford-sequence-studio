# 1.7.9：4462 输入耦合可选 AC（2026-11-11）

**新增开关：** 采集步骤增加"输入耦合"（DC / AC），默认 DC。选 AC 时 4462 在 ADC 之前加 3.4 Hz 高通，**把低温恒温器与接线带来的直流背景（热电势/偏置）在数字化前去掉**，让 ±316 mV 量程留给电流激发的交流信号。

**代价是要标定：** AC 耦合对各次谐波的衰减和相移不同（13 Hz 基频下 1f 约 −3.25%/+14.7°，2f −0.84%/+7.45°，3f −0.38%/+4.98°）。如果只需要"电流引起的响应"、不比较谐波比例，可把这组固定复数增益当常数校准掉；如果要比较 2f/1f 或 3f/1f，必须按同一基频逐次谐波标定。基频低于 50 Hz 时程序会在日志里提示这一点。

**它不是万能的：** AC 耦合只处理 0 Hz 附近（直流背景、慢漂移），对锁在 13 Hz 上的串扰、共模→差模转换、触发/marker 泄漏没有作用——这些分量在通带内原样通过，只差一个固定的幅相因子。如果零信号或超导态仍有读数，应先做基线扣除、检查布线/共模，而不是切换耦合。

**其他约束：** 同一次 PXI 运行内耦合方式必须一致（校验会拒绝混用）；切换耦合后高通需建立（τ≈47 ms），建议 `settle_s ≥ 0.5 s`；`dc_v` 在 AC 耦合下不再是真实偏置。旧方案载入后自动补为 DC，行为不变。

# 1.7.8：移除 4 个手动入口 + 允许 4462 逐步骤电流（2026-11-11）

**界面简化：** 删除"确认静止后复核角度""接受当前环境值并继续…""停止后解除未完成角度目标""停止序列并关源 / 磁场 HOLD"四个按钮及其全部相关逻辑。环境（含角度）未达标时程序只保持等待并记录日志，需人工点"停止运行"退出；运行失败或停止时引擎仍会自动关源、非正常结束时执行磁场 HOLD。

# 1.6.6：保存 X/Y/幅值，面板默认 X，显式相位设置（历史记录）

四通道、两次谐波都保存 X、Y、幅值，共 24 列电压数据（均为峰值标度，单位 V）：

| 通道示例 | 幅值 | X | Y |
| --- | --- | --- | --- |
| ai0 一次谐波 | ai0_V | ai0_X_V | ai0_Y_V |
| ai0 二次谐波 | ai0_2f_V | ai0_2f_X_V | ai0_2f_Y_V |

ai1–ai3 使用相同命名。幅值等于 sqrt(X²+Y²)，始终非负；X/Y 保留符号。面板默认显示 X，可以选择通道、1f/2f 以及 X/Y/幅值；切换仅改变显示。Delta 电压显示逻辑不变。

### 相位参数

- `marker_phase_deg`：6221 硬件相位标记，程序默认 90°，允许设置 0–360 的整数；通过 `SOUR:WAVE:PMAR` 显式发送。这里是本程序默认，不是仪器恢复出厂默认。
- `phase_deg`：1f 额外软件相位微调，默认 0°。
- `phase2_deg`：2f 独立额外软件相位微调，默认 0°。
- 软件采用正弦相位定义：若信号为 A sin(nωt+φ)，补偿前 X=A cosφ、Y=A sinφ。采样起点随 marker 移动，1f 减去 marker 相位，2f 减去两倍 marker 相位；再分别减去对应软件微调。
- 四路同一触发、同一窗口。源波形是 SIN，触发仍为 line1→PFI0 下降沿。0°或90°可与相应软件补偿配套使用，90°不是数字锁相必需条件。
- 合成信号验证了 marker 0°/90°下的相位不变性、负 X/Y、独立1f/2f微调和24列写入。真实链路的触发延迟、模拟滤波与线缆相移未自动校准；实际需要用已知参考信号校准微调值。2f 的 X/Y 定义不保证任意非线性信号天然落在 X 上。
- 旧方案缺少新相位字段时补上 marker=90°、2f微调=0°，保留原1f微调；记录在 run.json 的节点参数中。相比旧版未经补偿的2f X/Y，相位定义已改变，比较历史数据时应核对。
- 仍保持环境无限等待、完整稳定时间、坏点 NULL 后继续。

官方依据：Keithley 6220/6221 Reference Manual，7-9、7-24 及命令表；marker 范围 0–360°，并有90°示例。本版不是宣称90°是厂家固定要求。
https://download.tek.com/manual/622x-901-01%20(C%20-%20Oct%202008)(Ref).pdf

## 直接使用

解压到新目录，避免覆盖解压残留旧版SR830文件。安装带Tkinter的Python 3.10以上版本，双击start_windows.bat或执行`python main.py`。默认模拟模式，不访问真实仪器。

左侧选择2182A Delta或PXI-4462。DC模式已删除。新采集步骤、循环模板和已有采集步骤统一跟随该选择；连接和运行前检查一致性。连接后更换设备须先断开。打开方案会恢复其中保存的设备；如需更换，请在打开方案后选择。

触发设置无需选择，参数窗口已经删除这些下拉框：

| 测量方式 | 固定接线与程序行为 |
|---|---|
| 2182A Delta | 6221与2182A之间接RS232交叉线（null-modem）和8501整根Trigger Link；电脑GPIB接6221。Delta自动管理触发，不额外直连2182A GPIB。 |
| PXI-4462 | 6221线1接PFI0（SMB），测量电压接AI。程序固定线1、PFI0、下降沿。6221通过GPIB连接电脑。 |

默认旋转杆COM3。矩阵仅支持GPIB，例如GPIB0::20::INSTR。所有设备地址和电极映射须按现场填写。矩阵启用可选；测量电流为每步骤固定激励，范围和量程按模式设置。Delta保留原除数2，首次使用需以标准电阻核对读数归一化。

## 循环与数据

温度、磁场、角度可任意排列和嵌套。循环模板从外到内填写`temperature, angle, field`，可省略不用的变量。电极遍历统一由左下角设置。角度列表用“生成点列”指定1°步长，即可每转1°完成子层完整MR。

Delta电极遍历可使用显式电极循环，或“每点测完全部电极组合”，两者互斥。每个采集点先确认关源、设零，等待“断电后切换延时”，断开并切换矩阵，等待“切换后通电延时”，再通电测量。两段延时独立设置，新方案均默认0.5秒。关源未确认则停止，禁止切换。关闭矩阵时固定接线，只采集一次，不重复遍历电极表。原驱动为6×24矩阵，六个公共接口A–F；默认使用A→I+、B→I−、C→V+、D→V−，E/F未用。映射可核对配置，程序不擅自改变接线。矩阵原驱动没有机械继电器状态回读。

PXI-4462使用固定接线，必须关闭矩阵自动切换。整段序列开始即开启6221波形，温度/磁场/角度变化、等待和逐点采集期间持续ON；完成、停止、异常或暂停时关源，恢复时重新开启。同一段序列中的PXI步骤必须使用相同频率/相位/谐波/marker/DAQ设置（**电流可按步骤不同**，变化时在步骤边界关源重配后重开），也不能混入Delta步骤。

自动气压仅在左侧“自动气压设置…”窗口配置，包含唯一开关与低/高温气压；左侧显示开关状态。新方案默认低温侧3 mbar、高温侧10 mbar。按实测Probe温度判断：低于9.5 K采用低温侧压力，高于10.5 K采用高温侧压力，中间保持先前状态。关闭自动气压不影响VTI温度联动。温度步骤与设备配置窗口不再提供重复开关；旧方案的步骤级开关在导入时删除，统一遵循全局设置并提示迁移。更改设置仍需先断开连接。手动设置气压前需先关闭自动气压，防止后台覆盖。

旋转期间不查询角度，静默计时结束后单次回读。暂停在采集边界关源；停止等待当前驱动返回后关源并HOLD，原旋转协议无停止指令。退出不自动升温或退磁。

曲线Y轴固定电压V，X轴可选点号、温度、磁场、角度。运行/停止按钮置顶；序列与曲线分区可拖动，参数窗口可滚动。勾号表示选中，空框表示未选。每次运行单独保存run.json、data.csv、events.jsonl；数据保留固定激励、环境、电极及原始读数。PXI保留AI0–AI3多通道结果。

## 2026-09-16：6221 与 4462 电压单位核查

主程序 Delta 采集显式设置 `UNIT V`，将读数直接写入 `voltage_v`，绘图单位为 V；不额外除以 2，也不把电阻当作电压。6221 的电压来自配套 2182A，经 Delta 算法消除热电势。4462 当前路径保存交流锁相电压峰值，两者单位相同，但测量方式不同。

依据 622x Reference Manual 第 5 节，Delta 电压为三次采样组合 `(X-2Y+Z)/4`（交替周期校正符号）。对称 ±I 时对应 IR。修正底层驱动辅助 `resistance` 字段的旧换算：由 V/(HIGH-LOW) 改为 V/((HIGH-LOW)/2)，使其与主程序 `resistance_ohm` 一致。主程序原有电压数值不变。通过软件回归验证，未连接实机验证。

## 一口连接多个 pin（2026-09-17 更新）

电极组合表的 I+、I−、V+、V− 每一栏现在都支持一个或多个 pin。
例如 I+ 填 `12,11`，I− 填 `9`，V+ 填 `8,7`，V− 填 `6`。
默认 ABCD 接口下，这表示 A 接 pin 12 和 11，B 接 9，C 接 8 和 7，D 接 6。
同一个口的多个 pin 会电气并联；电流源设定的是该口的总电流，不是每个 pin 的电流。
每个 pin 仍只能属于一个口，不允许在同组或不同组重复填写。

手动切换或序列节点的 JSON `columns` 可写为 `[[12,11],9,[8,7],6]`；
旧格式 `[12,9,11,10]` 继续可用，matrix_rows 仍为四个不同接口。
逐点电极表、显式电极循环、手动切换及配置保存/载入均支持此格式。
CSV 示例列名：`V_12+11-9-8+7-6`，加号表示同口多个 pin，减号分隔四个口。
切换继续采用关闭输出、等待、全断开、设置新映射、等待后允许输出的流程。

协议说明为每个 pin 编码一个 0–6 数字，因此多 pin 可以编码成同一口；
验证帧 `[11233400,00000000,00000000]` 表示 A 接 1/2、B 接 3、C 接 4/5、D 接 6。
本次完成软件及模拟协议测试，未连接实体矩阵验证；界面显示仍是已发送命令，不是继电器回读。
原始“矩阵开关.zip”中的厂家资料不需要修改。

## 环境无限等待，坏点 NULL 后继续（2026-09-23 修正）

本版按以下规则运行：

- **环境没有总等待时限**：温度、磁场、气压、角度必须达到目标容差，并连续满足 stable_s 才继续。timeout_s 对环境节点只作日志提示，不终止序列。
- **每点等待照常保留**：连续稳定时间 stable_s、显式等待节点 seconds、采集前 settle_s、点间 interval_s、矩阵切换前后等待均保持原有执行逻辑。离开稳定容差后重新计时，不把之前已等待的时间拼接为连续稳定时间。
- **磁场安全回零/励磁暂停**：保留当前环境步骤、循环位置和数据文件，持续读取。你在电源前面板处理并继续，磁场重新到位并连续稳定后自动续测，不需要在程序中点继续。
- **坏电极不阻塞批量遍历**：Delta 超量程、NaN/Inf、空/非数值读数、点数异常及采集超时，当前组合写 NULL，继续下一组合/点；不原地无限重试，不永久禁用组合，下一环境点照常再测。PXI 整次采集超时或无效数值时，该点采集通道写 NULL 后继续。
- 单次通信与采集仍保留有限超时，使底层调用能返回程序。环境及设置/关闭输出的通信超时会保留位置重查；采集超时按上述 NULL 规则处理。Oxford 断开的连接可重新建立，重连本身不重发运动命令。
- 角度预计运动时间结束后仅自动回读一次；失败或未到位时等待人工确认机械静止后复核，不自动持续查询或重发运动命令。
- data.csv 保存有效电压或字面值 NULL；events.jsonl 保存无效读数原因和原始数据表示；invalid_points 统计写 NULL 的无效采集点数。
- Delta 无效采集确认关闭电流源后才跳过；PXI 保留原连续激励策略。矩阵切换前仍必须确认输出关闭。
- 手动“停止”仍有效。程序需保持运行，不支持关闭程序后的断点恢复。配置非法、非超时设备错误、文件写入失败等非等待类错误仍会报告错误。

### 磁场励磁失败后等待前面板恢复

磁场 FSET 设置或 RTOS 启动确认仍保留每阶段最多 3 次尝试，失败间隔 60 秒。耗尽后保留当前步骤、循环位置和数据文件，持续读取磁场，不再重发磁场命令，不自动结束实验。中途励磁暂停、停在非目标磁场或超过磁场节点 timeout_s 也继续等待；磁场 timeout_s 现在仅用于提示。

在励磁电源前面板处理故障并点击继续即可，无需在程序里点击继续。实际磁场进入原节点 tolerance，且电源处于 HOLD/CLMP 并满足连续 stable_s 后，程序自动接着当前步骤测量。等待期间不采集该磁场点、不跳过节点，环境显示继续刷新；可随时在程序里点击停止。若 FSET 写入未确认，请在前面板核对目标磁场，程序会显示本步骤要求的目标。

磁场设置/启动确认失败和磁场稳定等待遵循上述无限等待策略。原有 Delta 关闭输出、PXI 持续输出策略保持不变。程序必须保持运行，关闭程序后不支持从内存中的等待位置恢复。
