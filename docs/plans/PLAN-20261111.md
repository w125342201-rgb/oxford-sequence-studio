### 1.4 删除后的三个行为缺口（必须一起定掉）

**缺口 1：角度异常后没有任何出口。**
现状：旋转超差或回读失败 → `rotation_error` 置位 → 角度步骤永久等待；以前靠"确认静止后复核"或"停止后解除目标"脱困。
删除后：只能点"停止运行"。等待期间日志会持续提示，不会静默采数（`ensure_rotation_idle` 仍然禁止采集）。

| 选项 | 行为 | 评价 |
|---|---|---|
| **A1（推荐）** | 保持无限等待 + 日志明确"请停止后检查旋转杆" | 改动最小；符合 D-005（环境无限等待）；不会误采 |
| A2 | `rotation_error` 立即抛错，整轮失败 | 更快得到结论，但改变"环境异常不终止"的既有语义（D-005），影响面更大 |
| A3 | 计时结束后每 N 秒自动重试回读 | 与 S-4/1.7.5 决定冲突（禁止自动反复查询），不推荐 |

**缺口 2：失去 GUI 内手动 HOLD。**
现状：空闲时点该按钮 = 关源 + 磁场 HOLD。删除后：空闲状态无法从程序把磁体置于 HOLD；只能在运行中"停止运行"触发清理（非完成状态会 `hold()`），或直接用电源前面板。
→ 需确认你是否接受（推荐接受；若不能接受，可把该按钮改为菜单项而非删除）。

**缺口 3：`environment_overrides` 列与两个状态值。**

| 选项 | 结果 | 兼容性 |
|---|---|---|
| **B1（推荐）** | 保留列，永远写 `{}`；`accepted_by_operator` 状态不再产生 | CSV 仍 51/63/28 列，分析脚本不受影响 |
| B2 | 删除该列 | 变为 50/62/27 列，所有按列号/列数的脚本与测试断言要改（D 级变更） |

## 2. 变更 B：允许 4462 每步骤不同电流

### 2.1 现状（为什么现在不能改电流）

| 位置 | 现状 |
|---|---|
| `model.pxi_run_params`（341–359） | 收集全部启用 PXI 步骤，比较 `current_a`、`frequency_hz`、`phase_deg`、`harmonic_order`、`marker_phase_deg`、`daq_*` 等；任一不同即抛 `4462持续输出要求整段序列使用相同激励及DAQ设置` |
| `validate`（449） | 用 `pxi_run_params` 判断"是否 PXI 模式"以拒绝矩阵 |
| `Engine.run`（516） | `continuous_pxi = pxi_run_params(nodes)`，全程只用一个参数字典 |
| `Engine.run`（576） | 开跑前 `begin('resistance', continuous_pxi)`，之后**再也不重配** |
| `Engine.measurement`（476–482） | PXI 分支**不调用** `begin`，直接采 |
| `Engine.gate`（175） | 暂停恢复时用同一个字典重开 |
| 测试 | `test_continuous_and_switching.test_pxi_matrix_or_changed_excitation_rejected`（74）断言不同参数被拒 |

### 2.2 目标语义（哪些能变、哪些仍固定）

| 参数 | 是否允许逐步骤不同 | 理由 |
|---|---|---|
| **`current_a`** | ✅ **允许**（本次目标） | 6221 可在步骤边界重配幅值；CSV 已有逐行 `current_a`；电阻换算用同步的 `i_peak` |
| `harmonic_order` | ❌ 固定 | 决定 CSV 列集合（2f/3f 后缀不同），逐行不同会导致列无法定义 |
| `frequency_hz` | ❌ 固定 | 相位参考与解调频率全局一致；中途改频会让同一列不同含义 |
| `phase_deg` / `phase2_deg` / `phase3_deg` | ❌ 固定 | 参考坐标必须全程一致，否则 X/Y 不可比 |
| `marker_phase_deg` | ❌ 固定 | 同上，且影响 6221 触发 |
| `daq_device` / `daq_fs_hz` / `daq_duration_s` / `daq_range_v` / `daq_save_waveforms` | ❌ 固定 | 同一批数据的采样条件必须一致，否则量程使用率/噪声不可比 |
| `daq_channels` | ❌ 固定 `[0,1,2,3]` | 既有规定（D-008） |
| `samples` / `interval_s` / `settle_s` | ✅ 本来就是每步骤字段 | 无需改动 |

> 一句话：**只有"激励大小"这一维解耦，其余仍视为一段实验的固定条件。** 这样 CSV 列集合、解调参考、量程口径全部不变。

### 2.3 实现方案（按文件）

**① `studio/model.py` — 把"一致性"改成"契约 + 例外"**

```python
# pxi_run_params(nodes) 语义调整为：返回“固定条件契约”
keys = ('frequency_hz','phase_deg','harmonic_order','marker_phase_deg',
        'daq_device','daq_fs_hz','daq_duration_s','daq_range_v','daq_save_waveforms')
# current_a 从比较中移除
# 报错文案改为：4462持续输出要求整段序列使用相同频率/谐波/相位/DAQ设置（电流可按步骤不同）
```

- 函数名保持不变（`test_audit_175` 仍 import 它；避免额外改名成本）。
- 返回字典仍含 `current_a`（取第一个 PXI 步骤），仅用于"开跑时先按哪个电流起振"，不参与一致性判断。

**② `studio/engine.py` — 增加"当前已施加参数"**

新增属性 `self.pxi_applied = None`（`continuous_pxi` 继续表示固定契约）。

```python
# run()：仍按第一个 PXI 步骤的参数 begin（保持“环境扫描期间有激励”的既有行为）
first = 第一个启用 PXI 步骤的参数
self.retry_io('准备连续采集', lambda: self.b.begin('resistance', first))
self.pxi_applied = copy.deepcopy(first)

# measurement() 的 PXI 分支，在循环之前：
if self.pxi_applied is None or self._pxi_changed(p):
    self.retry_io('准备测量', lambda: self.b.begin(k, p))
    self.pxi_applied = copy.deepcopy(p)
    self.log(f'6221 交流激励切换为 {p["current_a"]:g} A（波形关闭后重配）')
    self.event('pxi_reconfigure', dict(current_a=p['current_a'], path=self.path))

# gate()：暂停恢复改用 self.pxi_applied
```

`_pxi_changed(p)` 比较 `begin()`/DAQ 真正消费的字段：`current_a, frequency_hz, marker_phase_deg, harmonic_order, daq_*`。由于校验层已禁止其它字段不同，实际只会因 `current_a` 触发。

**③ `studio/backend.py` — 原则上零改动**

`begin()` 已经是"off → 新建 DAQ → `configure_ac` → `verify_ac` → arm → init"，重复调用即可完成电流切换；`measure()` 的 `resistance` 用新建 DAQ 的 `i_peak`，与当前电流一致。

**④ `run.json` — 增加可追溯字段（只增不改）**

```json
"pxi_contract": { ...固定条件... },
"pxi_per_step_current": true
```

### 2.4 一次电流变化实际发生了什么（时序）

```
上一段采集结束（不关源，保持整段连续输出的原意）
→ 进入新 resistance 步骤，检测到 current_a 不同
→ begin(): SOUR:WAVE:ABOR → 输出关 → 置零 → :OUTP? 三查确认
→ 6221 设 compliance/freq/amplitude/marker → verify_ac（逐项回读）
→ arm + init（波形重启）
→ 等 settle_s（该步骤自己的字段）→ source_health → 采集 → 记录
```

时间成本：约 1–3 s/次切换（含 3 次关源确认与 `verify_ac` 回读），远小于一次环境设定。

### 2.6 边界与风险

| 风险 | 说明 | 缓解 |
|---|---|---|
| 切换瞬间无激励 | 必须关源后才能改幅值，样品会看到 1–3 s 零电流 | 日志明示；`settle_s` 已在采集前生效；必要时该步骤调大 `settle_s` |
| 热/磁历史 | 大电流→小电流后样品温度可能未恢复 | 属实验设计问题；建议切换后加 `wait` 或提高 `settle_s`（文档提示，不强制） |
| 相位参考 | 幅值变化不改变相位参考；但 6221 重启波形可能带来相位跳变 | 现有 `marker=90°` + 软件补偿的机制不变；首次实机需用标准电阻核对切换前后 X/Y |
| `verify_ac` 开销 | 每次切换多几次回读 | 可接受；不引入缓存（避免重犯 W-002 类问题） |
| 暂停/恢复 | 恢复时必须用**最近一次**参数 | `pxi_applied` |
| 与 Delta 混跑 | 规则不变（仍拒绝） | 校验保留 |
