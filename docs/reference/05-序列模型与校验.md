# 05 · 序列模型与校验

> **本文是说明性参考，不是规范。** 规范效力与唯一权威以 [开发规范](../开发规范.md) 为准；本文与规范冲突时，以规范为准并应在规范 §12 登记冲突。

序列文件就是一份 JSON：

```json
{
  "schema_version": 7,
  "config": { ... 34 个字段 ... },
  "nodes":  [ ... 节点树 ... ]
}
```

`studio/model.py` 是唯一的契约来源。**任何字段变化都必须同时改 `SPECS`（或 `CONFIG`）与 `upgrade_document()`**，否则旧文件载入时 `validate()` 会直接报"参数字段缺失或未知"。

---

## 1. 节点

每个节点结构固定为五项：

```json
{ "id": "36 位 hex", "kind": "resistance", "enabled": true, "params": { ... }, "children": [] }
```

- `id`：`uuid4().hex`，全树唯一；导入时重复即报错。
- `enabled`：`false` 的节点**不参与运行范围/电流/离散/交叉校验**，但仍校验结构、字段集、ID、基本类型、已删除功能。
- `children`：只有容器节点（`sweep` / `repeat` / `channels`）可以有；且容器**必须有**至少一个子步骤。
- 嵌套深度上限 **16 层**。

### 1.1 十种节点

| kind | 中文 | 参数 | 容器 |
|---|---|---|---|
| `temperature` | 设置温度 | `target` 4.0 K / `rate` 1.0 / `tolerance` 0.02 / `stable_s` 30 / `timeout_s` 3600 | 否 |
| `field` | 设置磁场 | `target` 0.0 T / `rate` 0.237 / `tolerance` 0.01 / `stable_s` 5 / `timeout_s` 3600 | 否 |
| `pressure` | 设置气压 | `target` 4.0 mbar / `tolerance` 0.2 / `stable_s` 5 / `timeout_s` 300 | 否 |
| `angle` | 设置角度 | `target` 0.0° / `rate` 0.5 °/s / `tolerance` 0.05 / `stable_s` 1 / `timeout_s` 900 | 否 |
| `wait` | 等待 | `seconds` 10.0 | 否 |
| `route` | 切换四端电极 | `name` / `columns` `[I+, I−, V+, V−]` | 否 |
| `channels` | 循环电极组合 | `routes` = `[{name, columns}, …]` | **是** |
| `repeat` | 重复子序列 | `count` 2（1–100000 整数） | **是** |
| `sweep` | 扫描环境参数 | `axis` temperature/field/angle、`values`、`rate`、`tolerance`、`stable_s`、`timeout_s` | **是** |
| `resistance` | 电压采集（所选设备） | 见下 | 否 |

### 1.2 `resistance` 的 22 个参数

| 参数 | 默认 | 用于 | 说明 |
|---|---|---|---|
| `mode` | `delta` | 公共 | `delta` / `pxi`；**跟随左侧设备选择**，不手填 |
| `current_a` | 0.1 | 公共 | 固定激励；非零；≤ `max_current_a` |
| `samples` | 1 | 公共 | 重复采样次数（1–100000） |
| `interval_s` | 0.0 | 公共 | 上次采集**记录完成后**的等待，不是严格周期 |
| `settle_s` | 0.2 | 公共 | 通电到测量的稳定等待 |
| `timeout_s` | 60.0 | Delta | **单次采集**超时；超时该点 NULL 后继续 |
| `nplc` | 5.0 | 2182A | 0.01–50 |
| `voltage_range_v` | 0.1 | 2182A | 0.01 / 0.1 / 1 / 10 / 100 V |
| `delta_delay_s` | 0.1 | 2182A | 0.001–9999 |
| `delta_divisor` | 1.0 | 兼容 | 固定为 1；≠1 直接报错 |
| `frequency_hz` | 13.0 | 4462 | 交流频率 |
| `harmonic_order` | 2 | 4462 | 附加谐波 2 或 3（1f 恒定采集） |
| `phase_deg` | 0.0 | 4462 | 1f 附加相位 |
| `phase2_deg` | −90.0 | 4462 | 2f 附加相位（热测量默认） |
| `phase3_deg` | −180.0 | 4462 | 3f 附加相位 |
| `marker_phase_deg` | 90 | 4462 | 6221 phase marker（0–360 整数） |
| `daq_device` | `""` | 4462 | NI 设备名；留空自动发现 |
| `daq_channels` | `[0,1,2,3]` | 4462 | **固定四通道**，只读显示 |
| `daq_fs_hz` | 51200.0 | 4462 | 1000–204800 |
| `daq_duration_s` | 1.0 | 4462 | ≤ 600 s |
| `daq_range_v` | 0.316 | 4462 | 六档之一 |
| `daq_coupling` | `dc` | 4462 | `dc` / `ac`（AC 为 3.4 Hz 高通；同一次运行内必须一致） |
| `daq_save_waveforms` | false | 4462 | 保存四路原始波形 NPZ（占磁盘） |

界面上只显示当前设备用得到的参数（`visible_fields()`），但**隐藏参数仍原样保存**，切换设备不丢设置。

### 1.3 电极映射格式

```json
"columns": [12, 9, 11, 10]                 // → I+=12, I−=9, V+=11, V−=10
"columns": [[12,11], 9, [8,7], 6]          // 一口多 pin，同口电气并联
```

规则：四个口；每口至少 1 个 pin；pin 为 **1–24** 整数；同一个 pin 只能属于一个口。

## 2. `CONFIG`（34 个字段）

`validate_config()` 要求**键集完全相等**（缺一个、多一个都报错）。

| 字段 | 默认 | 校验 |
|---|---|---|
| `vti_host` / `probe_host` / `ips_host` | 192.168.1.113 / .114 / .115 | 字符串 |
| `port` | 7020 | 1–65535 且为整数 |
| `io_timeout_s` | 5.0 | > 0 |
| `source_address` | `GPIB0::14::INSTR` | 启用时非空、不重复 |
| `matrix_resource` | `GPIB0::20::INSTR` | 必须匹配 `GPIBn::[0-30]::INSTR` |
| `matrix_rows` | `[1,2,3,4]` | 4 个不同的 1–6 整数 |
| `rotator_port` | `COM3` | 字符串 |
| `measurement_device` | `2182a` | `2182a` / `pxi` |
| `link_vti_temperature` | true | bool |
| `auto_pressure_enabled` | true | bool |
| `auto_pressure_low_mbar` / `_high_mbar` | 3.0 / 10.0 | `(0, max_pressure_mbar]` |
| `enable_source` / `enable_matrix` / `enable_rotator` | true / false / false | bool |
| `matrix_each_point` | false | bool |
| `point_routes` | A=[12,9,11,10], B=[8,5,7,6] | 非空、名称唯一、columns 合法 |
| `min_temperature_k` / `max_temperature_k` | 1.5 / 300.0 | `0 < min < max ≤ 300` |
| `max_field_t` | 14.0 | `(0, 14]` |
| `max_field_rate` | 0.237 | `(0, 0.237]` |
| `max_temperature_rate` | 10.0 | `(0, 100]` |
| `max_pressure_mbar` | 20.0 | `(0, 2000]` |
| `min_angle_deg` / `max_angle_deg` | 0.0 / 360.0 | `min < max` |
| `max_rotation_speed` | 1.0 | > 0 |
| `rotation_margin_s` | 1.5 | 0–3600 |
| `max_current_a` | 0.105 | `(0, 0.105]` |
| `compliance_v` | 105.0 | `[0.1, 105]` |
| `matrix_off_delay_s` / `matrix_settle_s` | 0.5 / 0.5 | ≥ 0 |
| `max_expanded_steps` | 100000 | > 0 |

交叉规则（`validate_config` 内）：

- `pxi` + `enable_matrix` → 拒绝；
- `enable_matrix` 但 `enable_source=False` → 拒绝；
- 两个启用的 VISA 地址相同或为空 → 拒绝。

## 3. 执行前校验：`validate(nodes, config, hardware=False)`

按顺序检查，任一失败抛出中文 `ValueError`（GUI 直接弹框）：

1. `validate_config(config)`。
2. 序列非空；递归遍历每个节点：
   - 节点键集 `{id, kind, enabled, params, children}` 完全一致；`id` 唯一非空；`kind` 在 `SPECS` 内；嵌套 ≤ 16。
   - **参数字段集与 `SPECS` 完全一致**；bool / 数值 / 字符串 / 列表类型逐项匹配，数值必须有限。
   - 非容器节点不得有 children；容器必须有 children。
   - 已删除功能：`mode='dc'`、`sweep.axis='pressure'`、`kind='sr830'` 一律拒绝（**即使在禁用的节点里**）。
3. 判断 `active`（自身及所有祖先 enabled）：
   - 非 active → 只递归子节点，跳过运行期校验（但上面的结构校验已做）。
   - active → `validate_discrete()`：`harmonic_order`/`voltage_range_v`/`daq_range_v` 必须是受支持的离散值。
   - 非负：`stable_s`、`seconds`、`interval_s`、`settle_s`。
   - 正数：`timeout_s`、`tolerance`、`nplc`、`voltage_range_v`、`delta_delay_s`、`frequency_hz`、`daq_fs_hz`、`daq_duration_s`、`daq_range_v`。
   - 整数：`count`、`samples` ∈ [1, 100000]。
   - 环境节点/扫描：值在物理范围内；`rate` 在 `(0, 上限]`；硬件模式下角度步骤要求 `enable_rotator`；手动气压要求自动气压已关。
   - `route`/`channels`：格式合法；启用逐点电极表时不得同时存在显式路由（禁用节点不算冲突）。
   - `resistance`：硬件模式下必须与已选设备一致、`enable_source`；`delta_divisor==1`；`check_currents`；NPLC 范围；Delta 延迟范围；PXI 的 marker 为 0–360 整数、谐波 ∈ {2,3}、采样点数合法、通道为 0–3 不重复、采样率能容纳谐波。
4. `pxi_run_params()`：若有 PXI 步骤，则**全部启用测量步骤都必须是 PXI**；**电流允许逐步骤不同**（D-024），其余关键参数必须一致（频率、1f 相位、谐波、marker、设备、采样率、时长、量程、波形保存，以及**当前所选谐波那一个**相位）。
5. `workload()` 的 `operations` 不得超过 `max_expanded_steps`；至少有一个启用步骤。

## 4. 点列精度：`span()`

"生成点列"用 Decimal 精确网格，**不做静默取整**：

| 轴 | 精度 |
|---|---|
| 温度 | 0.1 K |
| 磁场 | 0.001 T（1 mT） |
| 角度 | 0.1° |

- 起点/终点/步长都必须是该精度的整数倍，否则报错并说明是哪一项。
- 步长必须为正，方向由起止值决定。
- 默认"包含终点"：末段可短于步长；取消后严格等间距。
- 点数上限 100000。
- 已保存/手填点列**不做重新量化**，导入时不改写历史值。

## 5. 工作量：`workload()`

| 节点 | operations | acquisitions | csv_rows |
|---|---|---|---|
| `resistance` | `samples × routes`（逐点表时再加等量路由操作） | `samples × routes` | `samples` |
| 其他叶子 | 1 | 0 | 0 |
| `sweep` | 子项 × 点数 **+ 点数**（每个目标一次环境设定） | 子项 × 点数 | 子项 × 点数 |
| `repeat` | 子项 × count | 同 | 同 |
| `channels` | 子项 × 路由数（矩阵关闭时 ×1）**+ 路由数** | 同 | 同 |

示例：3 温度 × 5 磁场 × 1 次采集 = **33 个操作 / 15 次采集 / 15 行**。

> `operations` 是"环境设定 + 等待 + 路由 + 采集"的逻辑计数，**不是 SCPI 命令数，也不是预计机时**。

## 6. 设备选择契约

| 函数 | 语义 |
|---|---|
| `selected_mode(c)` | `2182a → 'delta'`、`pxi → 'pxi'` |
| `set_measurement_device(nodes, c, device)` | **显式 UI 选择**：把全部 `resistance` 步骤（含嵌套、禁用）的 `mode` 同步，PXI 时强制 `daq_channels=[0,1,2,3]`；保留各自量程/相位/谐波 |
| `require_measurement_device(c, p)` | 单步校验；不一致时提示"先断开连接再重新选择" |
| `validate_device_selection(nodes, c)` | 遍历启用步骤做上面的一致性检查（模拟/硬件都跑） |
| `normalize_pxi_channels(nodes)` | 导入时补字段 + 强制四通道（**不改 mode**） |

**载入方案不调用 `set_measurement_device`**：文件里保存的设备与参数原样恢复；要换设备，打开方案后在左侧重新选择。

## 7. schema 迁移链（`upgrade_document`）

| 版本 | 迁移内容 |
|---|---|
| 1 → 2 | 补 `matrix_each_point`、`point_routes`；`resistance` 补 `bias_a=0` |
| 2 → 3 | 只接受 `matrix_backend='visa'`；删除 `matrix_backend`/`matrix_port`（串口矩阵不能自动迁移，直接拒绝） |
| 3 → 4 | 拒绝 `iv`/`dcon`/`current_loop` 步骤；`resistance.bias_a` 必须为 0 才能删 |
| 4 → 5 | 按第一个启用测量步骤的 `mode` 推断 `measurement_device`；删 `enable_dmm`/`enable_sr830`；写入 `migration_notes` |
| 5 → 6 | 触发设置必须已是"线1/PFI0/下降沿"，否则拒绝；删除 `marker_line`/`daq_trigger`/`daq_edge`/`sr830_address` |
| 6 → 7 | `2182a + dmm_mode='dc'` 拒绝；删 `dmm_mode`/`dmm_address`；旧方案默认 **4/10 mbar** 与 `matrix_off_delay_s=0` |

之后还有四步**无条件规范化**（不论版本）：

1. 删除所有节点的 `auto_pressure` 参数（统一由全局设置控制），并追加迁移说明。
2. `delta_divisor` 一律改为 1.0（有改动就追加说明）。
3. 补 `rotation_margin_s=1.5`。
4. `normalize_pxi_channels()`：补 `marker_phase_deg=0`（**历史兼容，新建节点才是 90**）、`phase2_deg=0.0`、`harmonic_order=2`、`phase3_deg=-180.0`、`daq_save_waveforms=false`，PXI 步骤强制 `daq_channels=[0,1,2,3]`。

被拒绝的旧方案**不会**被自动删节点或改扫描类型——这是刻意设计：宁可拒绝，也不悄悄改变实验含义。

## 8. 最小可运行序列

```json
{
  "schema_version": 7,
  "config": { "...": "完整 34 字段" },
  "nodes": [
    { "id": "a1", "kind": "sweep", "enabled": true,
      "params": { "axis": "temperature", "values": [3.5, 4.0, 4.5],
                  "rate": 1.0, "tolerance": 0.02, "stable_s": 1.0, "timeout_s": 3600.0 },
      "children": [
        { "id": "b1", "kind": "resistance", "enabled": true,
          "params": { "mode": "delta", "current_a": 0.1, "samples": 1,
                      "interval_s": 0.0, "settle_s": 0.2, "nplc": 5.0,
                      "voltage_range_v": 0.1, "delta_delay_s": 0.1,
                      "timeout_s": 60.0, "delta_divisor": 1.0,
                      "frequency_hz": 13.0, "harmonic_order": 2,
                      "phase_deg": 0.0, "phase2_deg": -90.0, "phase3_deg": -180.0,
                      "marker_phase_deg": 90, "daq_device": "",
                      "daq_channels": [0,1,2,3], "daq_fs_hz": 51200.0,
                      "daq_duration_s": 1.0, "daq_range_v": 0.316,
                      "daq_save_waveforms": false },
          "children": [] }
      ] }
  ]
}
```

`model.example()` 生成的就是这个形状：温度 3 点 × 磁场 5 点 → **15 次采集 / 15 行 / 33 个操作**（矩阵关闭时）。
