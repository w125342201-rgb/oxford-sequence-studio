# 08 · 界面与交互

> **本文是说明性参考，不是规范。** 规范效力与唯一权威以 [开发规范](../开发规范.md) 为准；本文与规范冲突时，以规范为准并应在规范 §12 登记冲突。

`studio/gui.py` 是单文件 Tk 界面（901 行）。设计原则只有一条：**UI 线程只碰控件，仪器只在 worker 线程里**。

## 2. 左侧栏

### 2.1 测量设备（二选一）

- 下拉切换会调用 `set_measurement_device()`，**同步全部采集步骤**（含嵌套与禁用），并提示"切换了几个"。
- 连接后 / 运行中下拉被禁用；要换设备必须先"断开"。
- 下方常驻显示"本次连接选择：…"，是从后端对象读的**真实身份**，不是界面变量。
- 点"连接"时会再读一次界面值，避免只依赖 `<<ComboboxSelected>>` 事件（1.7.2 修复点）。

### 2.2 联动 VTI 控温

取消勾选 = 只写 Probe。切换**不发送**温控命令、也不撤销 VTI 已有设定；下一次温度命令才生效。运行中（含暂停）不可切换。

### 2.3 自动气压

只显示开关状态，"自动气压设置…"是唯一入口（启用开关 + 低温侧/高温侧压力）。更改需先断开连接。

### 2.4 Oxford 实时状态

温度 / VTI / 气压 / 磁场 / 角度 + `ACTN` 状态词。
刷新节奏：约 1 s 一次（worker 空闲循环）；角度**不轮询**，显示"运动中（不查询）"或"等待人工静止复核"。

### 2.5 手动控制

| 按钮 | 行为 |
|---|---|
| 温度… / 气压… / 磁场… / 角度… | 弹出 `Form`，确认后作为一个**单节点序列**提交运行（走完整引擎路径，因此照样落盘、照样有环境等待） |

> **2026-11-11 已移除**（规范 D-023 / W-008）：确认静止后复核角度、接受当前环境值并继续、停止后解除未完成角度目标、停止序列并关源/磁场 HOLD。
> 现在环境异常只能等待或点"停止运行"；运行失败/停止时引擎仍会自动关源并在非完成状态下执行磁场 HOLD。

### 2.6 当前电极命令

"启用矩阵开关"与"每点测完全部电极组合"两个勾选框直接写 `config`（需断开连接）。下方实时显示最近一次路由命令的名称与四端口映射——注意这是**已发送的命令**，不是继电器回读（设备无回读）。

## 3. 右侧：序列树

- 每行显示：图标文本（采集步骤显示 `2182A DELTA` / `PXI-4462`）、参数摘要（只显示当前设备可见的参数）、启用勾号。
- 禁用节点灰色；当前执行节点高亮（`node` 事件）。
- 双击 = 编辑；`Delete` 键 = 删除；选中时底部显示前 4 个参数的详情。
- "层级 / 启用"菜单：增加缩进（要求前一个同级是容器）、减少缩进、启用/禁用。

### 3.1 插入的三种方式

| 按钮 | 结果 |
|---|---|
| 插入同级 | 插到当前选中项之后；未选中则追加到根 |
| 加入循环 | 追加到选中容器（sweep/repeat/channels）的 children |
| 循环模板 | 一次生成"温度→角度→磁场"嵌套壳，外层可省略；电极遍历统一在左下角设置 |

## 4. 参数表单（`Form`）

所有参数编辑都走同一个 `Form`，因此行为一致：

- **只解析当前可见字段**（`visible_fields()`）：切换设备不会把隐藏字段的空字符串写回去。
- 离散参数（谐波、量程、设备）用只读下拉，标签来自 `instrument_options.OPTIONS`，保存时反查存储值；非法旧值会提示"不支持的值，请重新选择"。
- 列表参数用 JSON 文本 + 辅助按钮：
  - `values` → **生成点列**（`span()`，按轴精度校验）；
  - `routes` / `point_routes` → **编辑电极表**（`RouteEditor`，支持一口多 pin）。
- 相位参数旁有"应用热测量默认相位"（marker=90、1f=0、2f=−90、3f=−180）。
- 底部按模式显示接线提示（`wiring_hint()`）。
- 窗口可滚动、随窗口宽度换行；滚轮由全局单一处理器分发（每个应用只注册一组，销毁时注销）。

## 5. 绘图

| 项 | 行为 |
|---|---|
| 数据来源 | `deque(maxlen=20000)`，只保留最近 20000 次采集（文件仍保存全部） |
| 绘制窗口 | 最近 **3000** 次采集，标题注明 |
| 刷新节流 | 最快 **4 Hz**；若单次绘制耗时长，间隔自动放宽到 8× 绘制耗时 |
| 横轴 | `logical_point` / `acquisition_index` / `temperature_k` / `field_t` / `angle_deg` |
| 纵轴 | 固定电压 V |
| PXI 额外选项 | 谐波（1f/2f/3f，按本次安装的谐波动态给出）+ 分量（X/Y/幅值） |
| 通道筛选 | "通道 / 电极"下拉，`全部` 或单个 |
| 分组 | 按 `(path, 通道名, kind)` 分组，保证不同扫描轮次不连线 |
| 最新值 | 曲线上方按通道显示最新一次采集的数值，NULL 显式显示为 `NULL` |
| Delta 模式 | 隐藏谐波/分量控件（强制 1f/X） |

绘图完全在 Tk 主线程，只用 Canvas 图元；没有引入 matplotlib。

## 6. 运行日志

- `Text` 控件，最多保留约 1000 行（超出自动裁剪），带 `HH:MM:SS` 前缀。
- 空闲状态刷新失败：**相同错误每分钟最多一条**，错误变化或恢复立即提示（避免刷屏）。
- `error` 事件除了写日志还会弹 `messagebox`。

## 7. 互锁（哪些操作在什么时候被禁）

| 状态 | 禁止 |
|---|---|
| 未连接 | 运行、手动控制、角度复核、解除角度目标（"运行"提示先连接） |
| 已连接 | 修改设备配置、地址、限值、矩阵开关、逐点电极表、自动气压、测量设备下拉、模式下拉（都要求先断开） |
| 运行中（busy） | 所有序列编辑（插入/编辑/复制/删除/移动/缩进/启用）、打开/新建/保存方案、选择数据目录、断开、再次连接 |
| 运行中（含暂停） | 切换 VTI 联动、切换测量设备 |

这些检查分两层：`idle_required()` 管 GUI，`validate()`/`validate_device_selection()` 管执行前，后端 `begin/measure` 再查一次设备一致性。**三层都保留**，不要因为"UI 已经挡住了"就删后端检查。

## 8. 关闭与退出

`close_window()`：

1. 有未保存修改 → 询问；
2. 置 `closing`，若 busy 先请求停止；
3. worker 执行 `quit` job：`backend.close()`（关源 → 等矩阵断电延时 → 全断开 → 关闭连接）→ `emit('quit')` → 主线程 `destroy()`；
4. 清理失败会弹错误框提示"请检查仪器"。

**程序不自动升温、不退磁**；旋转杆无停止命令；强杀进程可能让 6221 保持输出。

## 9. 界面里的"红色/灰色"约定

| 元素 | 含义 |
|---|---|
| 状态行红色 | `quality_label` 连续无效 ≥ 10 时变红（只告警，不改变遍历规则） |
| 树中灰色 | 节点被禁用 |
| 树中青底 | 当前执行节点 |
| 环境值显示"—" | 无有效读数（未连接或该通道无效） |
| 环境值显示"读数失效" | 连续刷新失败，`stale` 事件 |
| 角度显示"运动中（不查询）" | 静默等待期间，协议禁止查询 |
