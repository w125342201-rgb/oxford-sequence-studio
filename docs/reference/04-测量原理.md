# 04 · 测量原理

> **本文是说明性参考，不是规范。** 规范效力与唯一权威以 [开发规范](../开发规范.md) 为准；本文与规范冲突时，以规范为准并应在规范 §12 登记冲突。

两种测量设备的物理链路完全不同，但**保存的单位都是伏特（峰值标度）**。

| | 2182A + 6221（Delta） | PXI-4462 + 6221（交流锁相） |
|---|---|---|
| 激励 | 直流，正负交替（`+I` / `−I`） | 正弦交流，频率 `frequency_hz`（默认 13 Hz） |
| 读数 | Delta 电压（3 次采样组合） | 1f 与所选谐波（2f/3f）的 幅值/X/Y |
| 每点列数 | 1 列 `voltage_v` | 4 通道 × 6 列 = 24 列 |
| 触发 | 6221 主控，自动 | 6221 line1 → PFI0 下降沿 |
| 适合 | 直流电阻、R–T、磁阻 | 弱信号、谐波、相位敏感响应 |

## 1. Delta 三点法

6221 与 2182A 的 Delta 模式按手册第 5 章的"三点采样"组合：

```
V_delta = (A − 2B + C) / 4      （A、C 为 +I 与 −I 的采样，B 为反向电流的采样；含逐周期极性校正）
```

在对称 ±I、线性电阻条件下 `V_delta = I × R`，所以 `R = V_delta / I`。

Studio 调用 `run_delta_once(high=+I, low=−I, delta_unit='V')`，驱动内部 `delta_current = (high − low)/2 = I`；`HardwareBackend.measure()` 再取 `readings[0]` 作为 `voltage_v`，并计算 `resistance_ohm = v / bias`。两条路径的除数一致。

### 1.1 Delta 除数 2 的来龙去脉

- 原始 `measureGUI/teslatronpt_mr_gui.py` 写的是 `resistance = voltage_delta / (2.0 * current)`。
- Studio 1.6.0 原样保留了 `/2`，并在 `params.delta_divisor` 里持久化。
- 1.6.3 按用户决定**移除额外除 2**，固定 `R = V/I`，`delta_divisor` 恒为 1（保留字段仅为兼容旧文件）。
- 为什么原来可疑：手册的 `(A−2B+C)/4` 在对称 ±I 下就已经等于 `IR`；再除以 `2I` 会让电阻**减半**。原代码把返回值解释成 `V(+I) − V(−I)`，与厂家定义冲突。
- 现状：**原始电压未改写，历史 CSV 不改动**；`validate()` 遇到 `delta_divisor != 1` 会报错要求重新导入旧方案。

> 这意味着：1.6.3 之前的 Delta 电阻列在数值上可能偏小一半。比较历史数据时必须先确认版本。使用绝对电阻前，请用标准电阻核对 `V/I`。

### 1.2 Delta 的超时与失败

`timeout_s`（默认 60 s）是**单次采集超时**。超时或读数无效 → 该点写 `NULL` 并继续（不是整轮失败）；但源顺从、过温、关源失败会让**整轮**停止。

## 2. 4462 数字锁相

### 2.1 采集

一次采集 = 一个 NI-DAQmx 有限任务：4 路 AI 同步采样，样本数取**整数个激励周期**：

```
n0     = max(8, round(fs × duration))
cycles = max(1, round(n0 × f / fs))
n      = round(cycles × fs / f)
```

限制：`8 ≤ n ≤ 2,000,000`、单点/单周期 ≤ 600 s、`1000 ≤ fs ≤ 204800`、所选谐波必须低于 Nyquist（校验条件 `2×h×f < fs`，即 `h·f < fs/2`）。

采样率用的是**任务实际回读值** `actual_fs_hz`，不是请求值。

### 2.2 解调：带权的联合最小二乘（不是简单乘参考再平均）

对每个通道，构造设计矩阵 `[1, sin(θ₁), cos(θ₁), …, sin(θ_h), cos(θ_h)]`，用 Hann 窗做加权最小二乘拟合：

```
X_h = 乘 sin(hωt + h·marker + phase_h) 的系数
Y_h = 乘 cos(hωt + h·marker + phase_h) 的系数
幅值 = hypot(X, Y)      （峰值 V，非 RMS）
```

要点：

- **不做整周期取整近似、不减均值、不猜硬件延迟**；频率必须与源时钟真实一致。
- 拟合条件数 > 1e8 或秩亏 → 报"病态拟合"，该点记 NULL（可加长采集时间）。
- 同时输出 `dc_v`、`residual_rms_v`、`fit_condition`、`window_enbw_hz` 供诊断。
- 3f 模式会**把 2f 作为干扰项一起拟合**（`harmonics = 1..h`），只为抑制短窗下强 2f 泄漏到弱 3f；导出的仍只有 1f 和 3f。

### 2.3 相位约定（最容易被误解的部分）

设采集窗口起点为 t=0，6221 的 marker 角度为 `m`，第 h 次谐波的附加相位为 `phase_h`：

| 分量 | 参考 |
|---|---|
| X_h | `sin(hωt + h·m + phase_h)` |
| Y_h | `cos(hωt + h·m + phase_h)` |

默认值：`marker=90°`、1f `0°`、2f `−90°`、3f `−180°`。

**为什么 2f 是 −90° 而不是 +90°**：欧姆电压 `A₁ sinθ` 给出 `X₁=A₁, Y₁=0`；理想低频热电压的交流部分是 `−A₂ cos2θ`，在 `m=90°、φ₂=−90°` 下 `X₂=A₂, Y₂=0`。若填 +90°，理想热信号的 X₂ 会**反号**。

**3f 的符号**：`I=I₀sinθ` → `ΔT ∝ (1−cos2θ)` → 电阻变化乘读出电流后，3f 电压为 `−[I₀D(dR/dT)/2]sin3θ`。选 `−180°` 使正 `dR/dT` 对应正 X₃。3f 是电压，**不是 dR/dT 本身**。

其余要点：

- 一次谐波**永远采集**；附加谐波 2f 或 3f 二选一，不是同时输出三组。
- 面板切换 1f/2f/3f 或 X/Y/幅值**只改变显示**，不改变采集。
- 未采集的谐波列在显示里是 NULL，不会用另一个谐波冒充。
- 同一运行的所有 PXI 步骤必须谐波一致。
- 旧方案缺字段的迁移：`marker`/`phase2` 缺失补 **0°**（历史行为），`harmonic_order` 缺失补 2，`phase3` 缺失补 −180°；**显式值一律保留**。

### 2.4 量程

| 档位 | 增益 | 备注 |
|---|---|---|
| ±0.316 V | 30 dB | 新建默认 |
| ±1 V | 20 dB | |
| ±3.16 V | 10 dB | |
| ±10 V | 0 dB | |
| ±31.6 V | −10 dB | |
| ±42.4 V | −20 dB | **无硬件过载检测** |

- 量程针对**含直流偏置、强 1f、弱谐波和干扰的总波形峰值**，不是"锁相灵敏度"，也不能理解成几十 nV 的分辨率。
- 程序在采样后检查波形是否超过回读限值（guard 上限硬性钳在 ±42.4 V），超 99.9% 判无效；这是软件检查，**不能替代硬件保护**，也发现不了被滤掉的瞬态/共模超限/前放削顶。
- 每个点记录请求量程、每路 `ai_min/ai_max` 回读、软件 guard 边界、增益诊断、峰值/均值/量程使用比例。
- 运行中**不自动换档**（避免给趋势引入增益台阶）；需要换档就在采集步骤里改。
- **输入耦合**：默认 DC；可选 AC（−3 dB @ 3.4 Hz）。AC 在 ADC 之前去掉直流背景，但会按频率改变幅相：13 Hz 下 1f 约 −3.25%/+14.7°、2f −0.84%/+7.45°、3f −0.38%/+4.98°。只关心电流激发响应时，可把这组复数增益当常数标定掉；若要比较 2f/1f 比例，必须逐次谐波标定。切换耦合后高通需建立（τ≈47 ms），建议 `settle_s ≥ 0.5 s`。**注意：它只处理 0 Hz 附近，不去除 f 上的串扰/共模/标记泄漏**——这些在通带内原样通过。判别方法：同条件 DC 与 AC 各测一点，若读数仍在（仅差约 3.25%、相位差约 15°），即属 f 域寄生，应做基线扣除或改善布线，而不是切耦合。

### 2.5 校准边界（务必记住）

- 触发只是"用 marker 启动任务"，**没有锁住 6221 与 NI 的时钟**。
- ADC、抗混叠滤波群延迟、线缆相移**都没有自动补偿**。
- 因此 X/Y 是"在保存的参考相位下的投影"，不是扣除硬延迟后的真实相位。首次实机应：标准电阻确认 1f 幅相 → 已知相干 2f/3f 注入确认符号与幅值 → 再上样品。
- 不宣称与 SR830 等效精度。

## 3. 两种设备的公共口径

| 项 | 约定 |
|---|---|
| 电压单位 | V，峰值标度（不是 RMS，不是 mV） |
| 电阻 | `V/I`；4462 为 `幅值/I_peak` |
| 无效值 | 字面量 `NULL`（字符串），**不是 0** |
| 未完成 | 空白单元格（没有测到） |
| 环境列 | 采集**之后**的回读值，不是与电压同步采样 |
| 时间 | UTC ISO 8601，`..._utc` 后缀 |

`NULL` 与空白的区别是数据分析里最容易出错的地方：`NULL` = 试过但无效；空白 = 根本没测（中途停止/电极未遍历到）。详见 [07-数据与文件格式](07-数据与文件格式.md)。
