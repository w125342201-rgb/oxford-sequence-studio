# 01 · 项目概览

> **本文是说明性参考，不是规范。** 规范效力与唯一权威以 [开发规范](../开发规范.md) 为准；本文与规范冲突时，以规范为准并应在规范 §12 登记冲突。

## 1. 这个程序解决什么问题

在 Oxford TeslatronPT 低温恒温器上做输运测量时，一次实验通常要沿多个环境轴扫描（温度、磁场、角度），每个环境点还要换多组四端电极接线，每次接线还要采集一次电压。手工做这件事的风险是：忘记录当前温度、在励磁半程采数、换电极时电流还开着、中途断开后不知道哪一点丢了。

Oxford Sequence Studio 把这件事变成一份可保存的 JSON 序列：

```
扫描温度 [3.5, 4.0, 4.5]
└── 扫描磁场 [0, 0.05, 0.10, 0.05, 0]
    └── 电压采集（当前所选设备）
```

引擎负责逐点等到位、逐组切换电极、逐次采集，并同时写三份东西：宽表 `data.csv`（给人看/给脚本读）、逐次原始记录 `events.jsonl`（可追溯/可恢复）、`run.json`（本次到底用了什么配置）。

## 2. 支持什么（1.7.8）

| 类别 | 支持 |
|---|---|
| 测量设备 | **2182A + 6221**（Delta 三点法，6221 主控） / **PXI-4462 + 6221**（交流激励 + 四通道同步数字锁相）——二选一，全局唯一 |
| 环境轴 | 温度（Probe，可联动 VTI）、磁场（iPS）、角度（旋转杆）、气压（仅手动设定） |
| 扫描 | 温度 / 磁场 / 角度 的任意嵌套扫描；`repeat` 重复；`channels` 电极循环 |
| 电极 | 矩阵逐点遍历（每点测完全部组合）或显式 `route` / `channels` 节点，二者互斥；支持一口多 pin 并联 |
| 谐波 | 4462：1f 恒定采集 + 附加 **2f 或 3f**（每通道导出 幅值/X/Y） |
| 数据 | 每点一行宽表；无效测量写 `NULL` 继续；环境缺失分级标记 |

## 3. 明确不支持（不要试图"顺手加回来"）

这些是**按用户决定删除**的功能，代码里保留了显式拒绝，而不是静默降级：

- **SR830**：连接、采集、配置、界面全部移除；含 SR830 的旧方案直接拒绝导入。
- **DC 测量**：删除；旧 DC 步骤不能自动转成 Delta。
- **I–V、扫电流、DCON、非零直流偏置**：不提供。
- **气压扫描**（`sweep.axis='pressure'`）：移除；只保留气压设定与自动气压管理。
- **2182A 与 4462 混跑**：一次运行只能一种设备；PXI 序列中混入 Delta 步骤会被拒绝。
- **PXI + 矩阵切换**：4462 是整段持续输出，禁止同时切换继电器。
- **程序退出后的断点恢复**：等待状态只在内存中，关闭程序即丢失（数据文件保留）。

## 4. 快速开始

### 4.1 模拟模式（默认，不碰仪器）

```powershell
python main.py
```

1. 左上角模式为"模拟"，点"连接"。
2. 已载入内置示例：温度扫描 → 磁场扫描 → 电压采集。
3. 点"运行"。曲线与日志出现，`数据目录`（默认 `./data`）下生成 `2026xxxx_xxxxxxxx/`。

无 GUI 的方式：

```powershell
python run_simulation.py examples/01_T_B_electrodes.json
```

### 4.2 真实硬件

1. 模式切"真实硬件" → "设备配置"填地址、启用 6221/矩阵/旋转杆、核对实验限值。
2. 左侧"测量设备（二选一）"选设备（会同步所有采集步骤）。
3. "连接" → "校验" → "运行"。

接线与地址见 [03-硬件与接线](03-硬件与接线.md)，**首次联机必须按 [09-测试与验证](09-测试与验证.md) 的验收边界逐项核对**。

## 5. 关键默认值（1.7.7 起）

1.7.7 按用户要求把新建步骤的默认工作点提到了设备上限侧。这些默认值只影响**新建步骤**，已保存方案保留自身参数。

| 项 | 默认 | 定义位置 |
|---|---|---|
| 励磁速率 | 0.237 T/min（本机上限） | `FIELD_MAX_RATE_T_PER_MIN` |
| 磁场稳定容差 | 0.01 T | `DEFAULT_FIELD_TOLERANCE_T` |
| 测量电流 | 0.1 A | `DEFAULT_SOURCE_CURRENT_A` |
| Compliance | 105 V | `SOURCE_MAX_COMPLIANCE_V` |
| 最大固定激励上限 | 0.105 A | `SOURCE_MAX_CURRENT_A` |

⚠️ 三条直接的物理后果（不是缺陷，是使用边界）：

1. **0.01 T 容差 vs 细步长**：底层 no-op 判据是 `max(0.012 T, 容差)`。步长 ≤ 10 mT 时若电源没真正起励，可能被判"已到位"。做细步长 MR 时**单独调小该磁场步骤的容差**（0.0002–0.001 T），不要改全局默认。
2. **0.1 A × 105 V = 10.5 W 会落在样品上**。Compliance 是限压不是限功率，建议按 `I × R_expected × 2` 设置。
3. **量程刻意未改**：2182A 仍 0.1 V 档（对应 R ≤ 1 Ω），4462 仍 ±316 mV 档（对应 R ≤ 3.16 Ω）。超出时在采集步骤里改档，否则整点 NULL。

## 6. 能力边界

程序已在实机长期使用。以下是和仪器行为直接相关、实际使用时值得知道的边界：

- 4462 的 ADC/滤波/线缆相移**未自动校准**，X/Y 使用保存的参考相位。
- Delta 的电阻换算固定 `V/I`；历史上「再除 2」的争议见 [04-测量原理](04-测量原理.md)。
- 旋转杆协议**没有停止指令**，「停止」只保证不再发新命令。
- 程序退出不会自动升温、退磁或解除矩阵；强杀/掉电可能让 6221 保持输出。
- 精度上不与 SR830 对标。
