## 1. 项目边界（不可协商）

### 1.1 定位

Oxford TeslatronPT 低温输运测量的**序列化执行器**：声明式 JSON 序列 → 环境到位 → 电极切换 → 电压采集 → 双份落盘（宽表 + 事件流）。GUI 只是编辑器与监视器，**不承担仪器控制职责**。

### 1.2 支持矩阵（1.7.9）

| 维度 | 允许 |
|---|---|
| 测量设备 | `2182a`（6221 主控 Delta）/ `pxi`（6221 交流 + NI-4462），**全局二选一** |
| 环境轴 | 温度（Probe，可联动 VTI）、磁场（iPS）、角度（旋转杆）、气压（仅设定） |
| 扫描 | temperature / field / angle 任意嵌套；`repeat`；`channels` 电极循环 |
| 电极 | 逐点遍历（`matrix_each_point`）**或** 显式 `route`/`channels`，**互斥**；支持一口多 pin |
| 谐波 | 1f 恒定 + 附加 **2f 或 3f**（二选一） |
| PXI 激励电流 | **每个采集步骤可独立设置**；频率/相位/谐波/marker/DAQ 条件仍须全程一致（D-024） |

### 1.3 禁止恢复（代码中已设显式拒绝，**不得删除这些拒绝**）

| 功能 | 现状 | 拒绝位置 |
|---|---|---|
| SR830 | 删除 | `upgrade_document`（kind=sr830）、设备枚举 |
| DC 测量 | 删除 | `upgrade_document`、`validate`（mode 只允许 delta/pxi） |
| I–V / 扫电流 / DCON / 非零直流偏置 | 不提供 | `upgrade_document`（iv/dcon/current_loop、bias_a≠0） |
| 气压扫描（`sweep.axis='pressure'`） | 删除 | `upgrade_document`、`validate` |
| 2182A 与 4462 混跑 | 禁止 | `pxi_run_params`、`validate_device_selection` |
| PXI 期间启用矩阵 | 禁止 | `validate_config`、`validate`、`Engine.route` |

> 这些是**用户决定**，不是技术债。恢复任何一项都属于 E 级变更（§11.1），需用户书面确认。

### 1.4 单所有者原则

同一时刻只有一个线程操作仪器；同一批仪器只有本程序的一个实例在操作。**不得**并行运行 `legacy/measureGUI/`、`legacy/GUI/` 里的旧程序。

## 2. 安全红线（MUST / MUST NOT）

| # | 规定 | 依据/位置 |
|---|---|---|
| S-1 | 关源必须**硬件确认**：`:OUTP?` 最多 3 次，返回 `OFF` 或有限 0 才算关闭；未确认 → 抛错、**禁止**后续矩阵切换、整轮失败 | `HardwareBackend.off()` |
| S-2 | 源异常（顺从 / 过温 / 溢出，`MEAS` 条件位 B3/B2/B0）→ **停止整轮** + 清理，**不得**降级为单点 NULL | `source_health()`、`test_audit_176` |
| S-3 | 运动命令超时或响应丢失：**只观测、不重发**（磁场 `FSET/RTOS`、旋转 `rotate_to_degree`） | `Engine._environment` |
| S-4 | 旋转计时未结束：**禁止**任何角度查询；计时结束后只自动回读**一次** | `HardwareBackend.service/refresh_angle` |
| S-5 | 磁场"到位"必须同时满足：残差 ≤ 步骤容差 **且** `ACTN ∈ {HOLD, CLMP}` | `Engine._environment` |
| S-6 | 不得自动放宽磁场容差、不得把历史值或目标值冒充实测值 | `field_not_started` |
| S-7 | 矩阵切换时序固定：关源确认 → 等 `matrix_off_delay_s` → 全断开+设映射 → 等 `matrix_settle_s` → 允许通电 | `Engine.route()` |
| S-8 | PXI 交流输出整段 ON；温度/磁场/角度变化与等待期间**不得**关源（**例外**：暂停、停止、异常、运行结束按 S-1 关源，恢复时重开；**电流变化时在步骤边界重配**，该次切换会短暂无激励） | `Engine.run()` `continuous_pxi`、`Engine.gate()` |
| S-9 | 环境值无效时**不得**伪造：缺通道记 `partial`，整段失败记 `unavailable`，停止记 `stopped` | `Engine.clean_environment/record` |
| S-10 | 程序退出不自动升温、不退磁；旋转杆协议无停止指令 | 全局 |
| S-11 | **Delta 流程不得加入逐点串口往返校验**（NPLC?/RANG?/:SYST:ERR?）。2182A 只接受单向写 NPLC/RANG | 决策 D-002 |

## 3. 测量与数据语义规范

### 3.1 单位与标度（不得混用）

| 量 | 规定 |
|---|---|
| 电压 | **V，峰值标度**（不是 RMS，不换算 mV） |
| 电阻 | `R = V/I`；4462 为 `幅值 / i_peak` |
| 磁场 | T；速率 T/min |
| 温度 | K；速率 K/min |
| 角度 | °；速率 °/s |
| 压力 | mbar |
| 时间 | UTC ISO 8601（`*_utc`） |
| 无效值 | 字面量 `NULL`；未测到 = 空白。**二者不得互换，不得写 0** |

### 3.2 Delta 定义（D-001）

- 6221 手册三点法：`V_delta = (A − 2B + C) / 4`；对称 ±I、线性电阻下等于 `I·R`。
- 程序固定 `R = V_delta / I`，**`delta_divisor` 恒为 1**；`≠1` 的旧方案在 `validate` 阶段被拒绝。
- **不得**恢复任何 `/2` 换算；历史 CSV 不得改写。

### 3.3 4462 解调定义（D-009/D-010/D-011）

- 每通道对 `[1, sin(θ₁), cos(θ₁), …]` 做 Hann 加权联合最小二乘（`fit_harmonics`）。
- `X_h` 乘 `sin(hωt + h·marker + phase_h)`，`Y_h` 乘 `cos(同角)`，`幅值 = hypot(X,Y)`，均为峰值 V。
- 3f 模式**必须**把 2f 作为干扰项一起拟合，但**只导出** 1f 与 3f。
- 一次谐波永远采集；附加谐波 2f/3f 二选一，**不得**同时输出三组。
- 不得引入"整周期取整近似"或"猜硬件延迟"。病态拟合（条件数 > 1e8 / 秩亏）→ 该点 NULL。

### 3.4 相位默认与迁移双轨（最容易写错）

| 场景 | marker | 1f | 2f | 3f |
|---|---|---|---|---|
| **新建节点**（`SPECS`） | 90° | 0° | −90° | −180° |
| **旧方案缺字段**（`normalize_pxi_channels`） | **0°** | 保留 | **0°** | −180° |
| **旧方案显式值** | 保留 | 保留 | 保留 | 保留 |

- 这两套默认值**不同是刻意的**，不得"统一"。统一会静默改变历史实验的参考坐标。
- 界面"应用热测量默认相位"按钮写入的是**新建**那套（90/0/−90/−180）。
- 2f 用 −90° 的符号推导见 [reference/04](reference/04-测量原理.md)；**不得**改成 +90°。

### 3.5 量程与输入耦合（D-009 / D-026）

- 六档：±0.316 / 1 / 3.16 / 10 / 31.6 / 42.4 Vpk；四路统一。
- 新建默认 **±0.316 V**；旧方案显式值保留。
- **±42.4 V 档不支持硬件过载检测**：必须写 `hardware_overload_supported=false`，`overload_detected=null`，**不得**解释为"确认无过载"。
- 软件 guard 上限硬性钳在 ±42.4 V，即使驱动回读更大。
- 运行中**不得**自动换档。

- **输入耦合**：默认 `dc`；可选 `ac`（4462 在 ADC 前加 −3 dB @ 3.4 Hz 高通）。AC 的定位是**省量程 / 去直流背景**（把 0 Hz 附近的偏置与慢漂移挡在 ADC 之外），**不是"去偏置"**；它**不去除任何 f 上的分量**——串扰、共模→差模转换、marker/触发泄漏、电感/电容耦合都在通带内原样通过（只被一组固定复数增益缩放与旋转）。因此零信号或超导态若仍有 f 读数，切 AC 耦合无效，应按基线扣除/布线改善/降频处理（见 §3.3 与 reference/04）。代价是各次谐波衰减与相移不同（13 Hz 基频：1f −3.25%/+14.7°，2f −0.84%/+7.45°，3f −0.38%/+4.98°），因此**必须在同一基频下用标准电阻或已知谐波注入重新标定**。代价是各次谐波衰减与相移不同（13 Hz 基频：1f −3.25%/+14.7°，2f −0.84%/+7.45°，3f −0.38%/+4.98°），因此**必须在同一基频下用标准电阻或已知谐波注入重新标定**。同一次 PXI 运行内耦合方式必须一致；`frequency_hz < 50` 时程序会记录警告提示该标定需求。

### 3.6 环境语义（D-005/D-015）

- 环境列是**采集之后**的回读，不是与电压同步采样。
- 环境步骤**无总等待时限**；`timeout_s` 只产生提示。
- 连续稳定：离开容差、暂停、通信失败都**重新计时**，不得拼接历史等待。
- 环境值**不可人工放宽**：未达目标或未满足连续稳定时只能继续等待（自 2026-11-11 起无 GUI 恢复入口，见 W-008）。

### 3.7 计数语义（D-019）

| 字段 | 定义 |
|---|---|
| `points` | 采集次数；仅为 `acquisition_count` 的兼容别名 |
| `acquisition_index` | 第几次采集（1 起） |
| `logical_point` | 一个采样点（跨全部电极组合），宽表 `point` 即它 |
| `route_index` | 逻辑点内电极序号 1..N |
| `csv_rows` | 首次完整落盘的逻辑行数 |

所有文档与脚本**必须**保持这套定义，不得把 `points` 当行数。

## 4. 序列契约规范

### 4.1 文件与 schema

```json
{ "schema_version": 7, "config": { ...34 字段... }, "nodes": [ ... ] }
```

- `schema_version` 当前 **7**，1.7.x 全程未变。
- `config` 键集**必须**与 `model.CONFIG` 完全相等（多一个/少一个都拒绝）。
- 节点结构固定五项：`id / kind / enabled / params / children`。

### 4.2 字段集封闭（最高频事故点）

**新增/删除任何参数字段，必须同时完成以下四处，否则旧方案全部无法载入：**

1. `SPECS[kind]`（或 `CONFIG`）中的默认值；
2. `validate()` / `validate_config()` 中的类型与范围；
3. `upgrade_document()` 的 `setdefault`（旧文件补齐）；
4. 测试：旧方案载入 + 往返保存。

### 4.3 节点与校验分层

- 10 种节点、22 个采集参数：见 [reference/05](reference/05-序列模型与校验.md)。
- 校验分四层，**四层都必须保留**：
  `validate_config` → `validate`（结构+数值+交叉）→ `validate_device_selection` → `backend.begin/measure` 的再次一致性检查。
- 禁用节点：跳过运行范围/电流/离散/交叉校验，但**仍校验**结构、字段集、ID、基本类型、已删除功能。
- 匹配规则：`validate()` 返回的"执行操作数"是逻辑计数，**不是** SCPI 命令数或机时。
- PXI 一致性：除 `current_a` 外（频率、1f 相位、谐波、marker、DAQ 设置），整段序列必须相同；`current_a` 允许逐步骤不同（D-024）。

### 4.4 迁移与拒绝

- 无法自动转换的旧方案**必须拒绝**并给出可操作提示，**不得**静默删节点、改扫描类型或改除数。
- 迁移链 1→7 见 reference/05；新增迁移必须 `VERSION+1` 并写 `migration_notes`。

### 4.5 设备选择（D-007）

- 显式 UI 选择 → `set_measurement_device()` 同步**全部**采集步骤（含嵌套与禁用）。
- **载入方案不调用**该函数：文件里的设备与参数原样恢复；要换设备，打开后重新选择。
- 连接后锁定设备身份；`run.json` 与日志必须记录本次设备。

### 4.6 默认值单一来源（D-012）

- 硬件上限/默认值只允许定义在 `model.py` 顶部常量：`FIELD_MAX_RATE_T_PER_MIN`、`SOURCE_MAX_CURRENT_A`、`SOURCE_MAX_COMPLIANCE_V`、`DEFAULT_SOURCE_CURRENT_A`、`DEFAULT_FIELD_TOLERANCE_T`。
- `CONFIG` 上限与 `SPECS` 默认值**必须**引用同一常量，不得写第二份字面量。
- 默认值只影响**新建**；已保存方案保留自身参数，迁移不得重写。

## 5. 执行流程规范

### 5.1 生命周期（顺序不得调换）

```
校验 → 建目录 → 写 run.json(running) → 开 events/csv → PXI 开波形
→ execute → 清理(off, 非完成时 hold) → 重写 run.json(final)
```

### 5.2 环境等待（D-005/D-006）

- 无限等待；每 0.5 s 一轮（模拟 0.05 s）；每 ≥1 s 真读一次环境。
- 磁场：`no_op_ramp` 且实测超容差 → 写 `field_not_started` 并等待；**不自动放宽**。
- 磁场励磁失败后：保留进度、不重发命令、等前面板恢复，到位且稳定后自动续测。
- 角度：静默等待 → 单次回读 → 失败/超差则**保持等待**（无人工复核入口，见 W-008），日志提示"停止后检查旋转杆"；只能通过"停止运行"退出。

### 5.3 致命 vs 继续（D-003/D-004）

| 类别 | 处理 |
|---|---|
| Delta 超时/非数值/点数≠1/超量程；4462 过载/无效/超时 | 该点 `NULL`，**继续** |
| 连续无效 ≥10 | 告警 + 每 10 次 `invalid_streak`，**仍继续** |
| 环境回读无效（控制轴/Probe+压力/联动 VTI） | **无限重试**，阻塞新采集，不算失败 |
| 源顺从/过温/溢出、关源未确认、配置错误、文件写失败、矩阵命令失败 | **整轮失败** + 清理 |

### 5.4 暂停 / 停止 / 恢复

- 暂停在**节点或采集边界**生效：关源 → `pause` 事件 → 空转（不读环境）→ 恢复时重建测量准备 → `resume`。
- 停止 = 置位 → `Stopped` → `finally` 关源；非完成状态再 `hold()`。
- **停止不是急停**；旋转杆无法撤回已发出的运动。

### 5.5 落盘顺序（不得调整）

`finite_tree` → `acquisition` 事件 → 环境回读 → 组装行 → `point` 事件 → 宽表 `seek/truncate/flush/fsync` → UI。

> `acquisition` 先于环境回读，是"环境失败不丢点"和 `recover_points.py` 可用的前提。

### 5.6 清理（S-1/S-10）

`off()` 任何一步失败 → 记录 `cleanup_errors` + 状态降级 `cleanup_failed` → 用户必须现场检查。**不得**吞掉清理异常。

## 6. 数据与兼容规范

### 6.1 铁律：按列名读，不按列号

### 6.2 列数演进（历史 vs 现行）

### 6.3 事件类型不得重命名（分析脚本依赖）

## 12. 冲突处理

1. **发现冲突**（规范 ⇄ 代码 ⇄ 文档 ⇄ 现场）：立即停止相关改动。
