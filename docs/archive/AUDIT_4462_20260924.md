# NI 4462 数字锁相深度复核

复核日期：2026-09-24。交付版本：Oxford Sequence Studio 1.6.7。

## 1. 结论与证据边界

你的质疑是有依据的：有数字锁相函数，不等于四通道、两种谐波已经正确采集并保存；能测到一个合理电阻，也不等于微弱2f的幅值和符号可信。

本次读取了两个实际压缩包、原分立AC测量界面、当前采集/保存/显示代码，并直接调用归档旧算法和修改后的生产算法进行了独立解析信号测试。没有连接6221、4462、SR830或低温设备，没有实机精度验收。现版本应作为“软件修正、待台架验收版”，不能直接标成SR830等效替代品。

确定发现并修正：

1. 原分立程序与1.6.6采用相同的取整频点DFT和单独的1f/2f投影。Hann窗不保持相邻频率的正交性，短窗口会把强1f误判为2f；非整周期还会有严重幅相偏差。
2. 硬件采集一直用请求采样率计算参考，没有读取DAQmx实际配置采样率。
3. 耦合设置失败被忽略；所谓关闭IEPE使用的属性不是当前NI Python API所列的激励源属性。
4. 采集返回缺失通道、非有限值以及接近输入量程端点时，原来缺少完整的前置检查。新增检查并接入已有NULL继续流程。
5. 缺少marker字段的旧方案不应一律被赋予90°；迁移补为历史0°，已有显式值不改，新建方案仍显式默认90°。

没有靠猜测修改：6221波形、触发线、下降沿、采样率请求值、硬件滤波选项、环境等待和2182A/Delta流程。没有直接套用原程序注释里的“-19°”或把63个样本作为所有情况下的总延迟。

## 3. 官方手册核查：触发、采样与硬件相位

### 3.1 6221

手册规定波形幅值是峰值，不是RMS；marker可选0–360°，正弦的0°对应过零，脉冲宽度1 µs；marker输出线不能与其他已分配触发线冲突。默认线3与本程序显式线1要区分；手册命令表的PMAR默认180°也不等于程序默认值。参考：[Keithley 622x Rev.C，7-5、7-9、7-29及命令表](https://download.tek.com/manual/622x-901-01%20%28C%20-%20Oct%202008%29%28Ref%29.pdf)。

源码明确SIN、零偏置、无限波形输出、marker启用/线1/指定角度。新建方案90°只是用户偏好。marker=0或90在正确参考变换后应给出同一物理X/Y，不应为了“让X大”盲改marker或软件相位。

已下载并直接检查手册7-9页Figure 7-3原图：marker空闲高电平，指定相位处产生下降沿、低电平持续1 µs后回高。因此线1接PFI0并保留下降沿有图示依据，不是拿触发输入要求推断输出。现场仍须用示波器同时看电阻电压和marker，确认过零方向、脉冲前沿、传输/输出延迟及实际线号。即使两沿都能触发，1 µs边沿差在13 Hz仅0.00468°、2f为0.00936°，不能解释任意几十度偏差。

### 3.2 四通道与采样率

NI规格明确4462为四路同时采样、24位ΔΣ ADC；同一Task、统一采样时钟和统一开始触发是本程序采用的方式。四路同步不等于四路增益/相位完全一致。NI还有独立的通道间增益/相位误差规格。[NI 4461/4462 Specifications，输入及通道匹配](https://docs-be.ni.com/bundle/ni-4461-4462-specs/raw/resource/enus/373770k.pdf)

1.6.7在Task启动后读取samp_clk_rate并用于解调、结果fs_hz和duration_s，同时记录请求值、实际值、N、物理通道、回读量程及触发设置。注意：DAQmx返回的是实际配置率，不是外部频率计实测的晶振频率，仍不消除NI与6221的时基误差。

N仍按请求时长取接近整周期的整数样本；整数样本一般不能实现绝对整周期。低频时会至少取得约一个基波周期，实际时长可能明显长于请求值。新算法不依赖整数周期，但短窗口的噪声和条件数仍需关注。

### 3.3 滤波群延迟及启动

NI表中在51.2 kS/s时ADC滤波延迟为63样本，即1.23046875 ms。13 Hz时对应5.7586°，26 Hz为11.5172°。低采样率的延迟还取决于低频抗混叠选项，不能通用63。NI说明数字触发后的前若干输出样本可能对应触发前的模拟输入时间。[NI DSA Analog Input：Filter Delay](https://www.ni.com/docs/en-US/bundle/pci-pxi-pxie-usb-443x-446x-449x-feature/page/ai.html)

若仅考虑这样的滤波延迟τ，输入相位会含-2πhfτ；若还有触发/输出延迟，必须一起建模。程序没有自动添加固定相位补偿，避免双重补偿或错误符号。新增只读诊断记录ai_filter_delay及其单位、抗混叠属性；不支持时明确记录unavailable。不能把查询失败解释成“延迟为零”。[NI Python通道API](https://nidaqmx-python.readthedocs.io/en/stable/task_channels.html)

每点新建任务不一定造成随机相位漂移：理想稳定marker可重复定义起点；但现程序未跟踪每个marker，也没有让两个设备共用时基。采样边界量化、设备重启、源相位变化、滤波历史和时钟失配必须实测。不要把多次独立窗口的相位直接解释为样品物理相位变化。

逐点settle_s在建Task前等待，不能证明建Task后的滤波启动已经充分稳定。此次没有凭猜测丢弃固定样本，也未更改为持续DAQ任务。实机应比较首窗与后续窗、不同窗口长度、不同启动方式；若需丢弃L点，参考时间必须同时增加L/fs，不能只删数据不改相位。

低频保持DC耦合有依据：NI AC耦合-3 dB频率3.4 Hz，低频幅相不能忽略。此次将耦合失败由静默忽略改为明确报错，并使用ai_excit_src=ExcitationSource.NONE关闭激励；失败不会当作正常测量继续。单个BNC即一通道，中心/屏蔽分别为正/负，不能按原注释把相邻BNC误当差分正负端。

高频使用还必须让2f处于实际抗混叠滤波器通带，不能只检查低于Nyquist。当前算法拒绝Nyquist及以上，但不自动保证通带平坦性；本次13 Hz等低频用例不能外推到高频精度。

## 4. 算法定义、错误机理与修正

定义窗口内模型：

v(t)=C+X1 sin(ωt+r1)+Y1 cos(ωt+r1)+X2 sin(2ωt+r2)+Y2 cos(2ωt+r2)+残差。

r1=marker+phase1，r2=2×marker+phase2；两个phase独立。若真实信号为A sin(hωt+φ)，得到X=A cos(φ-rh)、Y=A sin(φ-rh)、幅值hypot(X,Y)。φ相对于所选sin参考；正Y对应超前的正cos分量。phase2不自动等于2×phase1：纯时间延迟部分会倍频，但其他频率响应未必满足。

全部CSV电压均为峰值分量。与SR830对照前X、Y、幅值都除√2。6221输入的交流幅值也为峰值；线性电阻的峰值比等于RMS比。幅值电阻A1/Ipk永不保留电压极性，不可替代X1/Ipk。

旧算法k=round(fN/fs)实际测的是kfs/N，不是指定f；去普通均值再乘Hann也不是同时拟合DC。Hann的coherent gain归一只修正窗衰减，不消除正负频率项、DC和其他谐波的互相投影。“加窗后幅值精确”“总比矩形窗抑制40 dB”都不是普遍成立的结论。

新算法：以精确参考频率构造DC、1f sin/cos、2f sin/cos共5列，最小化Σw(v-model)²，w为对称Hann；用sqrt(w)加权后通过lstsq求解。没有取整频点，不先减样本均值，不将Hann再次平方。病态矩阵或不合法频率明确拒绝；结果附条件数、DC与残差RMS。它是有限窗口的数字相敏解调/加权正弦拟合，不是跟踪型锁相环，也不是SR830滤波器的逐点复刻。

单独digital_lockin接口改成单频+DC拟合；正式四路acquire_one必须调用联合fit_harmonics，不能各调一次单频函数替代联合拟合。

### 4.1 Hann与SR830时间常数

以下为公式推导，不是实机噪声指标。对称Hann的双边窗ENBW为fs·Σw²/(Σw)²≈1.5/T；对应归一低通的单边ENBW≈0.75/T。1秒Hann不能称为“SR830时间常数1秒”。长窗口近似下，匹配单边ENBW的RC时间常数如下：

|SR830斜率|ENBW|与1秒Hann约0.75 Hz匹配的τ|
|---|---|---|
|6 dB/oct|1/(4τ)|0.333 s|
|12 dB/oct|1/(8τ)|0.167 s|
|18 dB/oct|3/(32τ)|0.125 s|
|24 dB/oct|5/(64τ)|0.104 s|

SR830表中99%稳定等待约5τ、7τ、9τ、10τ；同步滤波会进一步改变低频响应。匹配ENBW仍不匹配瞬态、旁瓣、死时间、模拟输入噪声、动态储备和参考追踪能力。[SR830手册3-21、滤波与RMS定义](https://www.thinksrs.com/downloads/pdfs/manuals/SR830m.pdf)

短窗口联合拟合各基函数不正交，不能仅拿1.5/T预测每个分量的噪声。应使用估计矩阵B=(AᵀWA)⁻¹AᵀW，白噪声协方差σ²BBᵀ；附带脚本独立计算该预测并与200次试验对比。

环境无限等待和单次通信/采集超时不是一回事：前者保持进度等待你在电源前面板处理；后者让线程能响应停止，无效电极读数写NULL。没有关闭磁体安全策略、自动回零保护或软件手动停止。未知错误和配置错误仍可能停止，不能许诺“任何错误永不停机”。逐点稳定等待没有缩短；模拟模式的加速不代表实机稳定时间。

## 7. 二次非线性与 2f 相位约定

以下是参考定义下的解析推导，不是对具体样品的现象鉴定。

设I=Ipk sinωt，准静态V=R1 I+αI²，则：

V1=R1 Ipk sinωt；
V2=-(αIpk²/2)cos2ωt，另有DC=αIpk²/2。

所以在本程序的零软件相位约定下，理想二次非线性出现在Y2=-αIpk²/2，而不天然出现在X2。面板默认X没有问题，但必须先约定并校准2f相位；不能因X2≈0就说没有2f。若选择phase2=-90°，上述理想项旋转到正X2；这只是坐标约定，不是所有样品都应该设-90°。

若二次项来自交流加热（焦耳热 P∝Ipk²[1-cos2ωt]/2），温度梯度还要经过热传递函数 H(2ω)，故 2f 带有热相移，不能用 1f 电阻校准值直接推断 2f 热相位。加热电流、检测电流、样品电压的物理路径必须区分。

应保留有符号X/Y及相位：幅值始终非负，会抹掉电极反接或响应符号变化的信息；幅值减背景也不等于复数信号减背景。推荐先在固定校准坐标中做复数背景扣除，再看幅值与相位。

2f 随 I² 增长并不足以单独证明真实的二次响应。接触整流、源本身 2f 失真、非对称削顶、普通热电效应及其他热磁电效应都能产生 2f。应结合电流标度、±B、角度依赖、电压引线反接、温度跨转变与热频响逐项排除。

## 8. 实机验收：操作步骤与通过条件

先离开真实样品，用标准电阻/信号源验证；保持现有设备保护，不旁路磁体安全机制。

### A. 接线与配置记录

1. 记录4462型号/序列号、NI-DAQmx及Python包版本、6221固件、校准日期、线缆/屏蔽/前放、输入量程/耦合。
2. 高阻示波器同时观察标准电阻电压和marker线1；确认公共参考的接法符合设备手册，避免把浮地/差分负端随意短接地。
3. 依次marker=0、90、180、270，检查相位点、脉冲宽度、边沿和输出延迟。软件设定与硬件观察不一致时先查接线/固件/命令错误，不靠软件任意旋转掩盖。

### B. 标准电阻1f与相位稳定性

1. 选择低感、已校准四线电阻。例：100 Ω、Ipk=10 µA，预期Vpk=1 mV、Vrms≈707.107 µV；须保证功耗和负载电压适当。
2. 同一信号接入四路，使用相同配置；防止错误接地或负载改变信号。记录至少100点。逐路看X/Y/A、均值、标准差、通道间偏差。
3. 用各路1f的atan2(Y,X)测相位；当前GUI相位微调是全通道共用，若通道差异超预算，应采用外部逐通道校准分析或另行实现有记录的校准表，不能靠公共偏置解决。
4. marker从0改90，保持软件对应角度一致，恢复后的X/Y应在合成不确定度内一致；交换电压引线，X/Y应都反号，幅值不变。
5. 在每次重新运行、6221重启后重复；f可取7、13、17 Hz，另试51.2/102.4 kS/s、1/2/5秒，记录相位对采样率、频率和时间的依赖。不要因偶然一次Y≈0就锁定参数。

### C. 已知2f注入

1. 使用能保持同源相干的双频信号源/AWG合成DC+1f+2f，并提供兼容的同步触发；离线台架接法不要直接冒充程序的6221运行接法。若使用两个信号源，它们必须有经验证的相位/频率关联，不能只设置相同数字频率。
2. 先在易测幅度（如1f=1 mV、2f=10 µV）测试2f相位0、90、180、-90，预期(X2,Y2)依次为(A,0)、(0,A)、(-A,0)、(0,-A)。
3. 保持强1f，逐级减小2f，直到达到你需要的检测下限；用校准过的衰减链验证注入值，而不是仅相信AWG显示可直接准确输出10 nV。
4. 2f=0、仅1f、仅2f、叠加DC、叠加工频各测；目标是测出“假2f底”和相位不确定度。
5. 分别在DAQ输入端和前放端制造可控限幅；前者应NULL，后者可能产生有限假2f，这正是必须检查时域波形的原因。

### D. SR830对照

1. 两者测同一稳定信号，以同一marker作为参考并核对触发极性；SR830依次测1f和2f，单台SR830不能同时独立输出两个谐波的完整X/Y。
2. 统一峰值/RMS和参考相位，记录所有增益、耦合、line notch、sync filter、时间常数、斜率、过载标志。
3. 先关额外陷波/同步滤波做可解释的基线，再逐项开启比较；按表近似匹配ENBW，不要求无法设置的精确τ档位，可计算实际带宽或改窗口T。
4. 等待SR830实际滤波稳定，比较多点均值、标准差、漂移和电流扫幅下的线性；不能只截图两次读数接近。

### E. 验收记录与判据

预先给出你的实验所需的最小2f信号Vmin、允许相位误差和相对误差。建议判据形式：1f增益偏差小于电阻/电流源/DAQ合成不确定度；2f零输入的系统背景与统计误差明显小于Vmin（可用≤0.1 Vmin作项目目标而非厂商保证）；符号反转和marker不变性正确；100次启动及长时间运行无超预算相位漂移。未给出Vmin前不能宣称某个统一“高精度”指标达标。
