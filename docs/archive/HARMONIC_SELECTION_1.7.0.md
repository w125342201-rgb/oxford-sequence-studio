# 1.7.0：二次／三次谐波选择

交付日期：2026-09-26。本版在1.6.9基础上增加四通道1f＋3f测量选项，保留1f＋2f。没有完成新的硬件实测。

## 使用方法

1. 选择PXI-4462测量设备，双击序列中的“电压采集（所选设备）”步骤。
2. 在“附加谐波（一次谐波始终采集）”下拉框选择“二次谐波2f”或“三次谐波3f”，应用并保存方案。
3. 界面显示所选谐波的独立相位参数。切换谐波不会覆盖另一个谐波已经设置的相位；“应用热测量默认相位”按钮则会明确恢复marker、1f、2f、3f的默认值。
4. 数据面板可选1f、2f、3f，再选择通道和X/Y/幅值。默认仍显示X。面板切换只改变显示，不改变正在采集的谐波；未采集的谐波显示NULL，不会用另一个谐波冒充。

一次运行中所有4462测量步骤须使用一致的谐波和DAQ设置。需要改变采集谐波时，结束当前运行，修改参数后开始新运行。数据面板选择“3f”本身不会开始采集3f。

## 默认相位与物理含义

| 参数 | 默认值 |
|---|---:|
| 6221 marker触发位置 | 90° |
| 1f附加解调相位 | 0° |
| 2f附加解调相位 | −90° |
| 3f附加解调相位 | −180° |

第h次谐波的X参考为sin(hωt+h×marker+phase_h)，Y参考为同角度的cos。三次谐波自动补偿的是3×marker，不是2×marker。

3f默认值针对上一轮讨论的低频自加热场景：I=I0 sinθ，温升ΔT=D(1−cos2θ)，电阻变化近似为(dR/dT)ΔT。乘上读出电流后，3f电压为−[I0 D(dR/dT)/2]sin3θ。因此选择−180°参考，可使正dR/dT对应正X3，负dR/dT仍对应负X3。相位0°也能把理想信号放在X3，但符号与此约定相反。

这些是明确的参考坐标默认值，不是自动硬件相位校准。热滞后、线路或ADC/滤波延迟可产生Y分量，程序保留X/Y/幅值。3f数据仍是电压，不直接标成dR/dT；定量换算还需要温度振荡幅度，其他三阶非线性和源失真也可能贡献3f。

## 保存内容

四个输入ai0–ai3在同一个DAQ任务内同步采样，所选谐波都从同一段原始波形解调，不轮流切换硬件通道。

| 采集模式 | 每通道电压列名（ai0示例） |
|---|---|
| 1f＋2f | ai0_V、ai0_X_V、ai0_Y_V、ai0_2f_V、ai0_2f_X_V、ai0_2f_Y_V |
| 1f＋3f | ai0_V、ai0_X_V、ai0_Y_V、ai0_3f_V、ai0_3f_X_V、ai0_3f_Y_V |

每行仍为7列基础信息＋24列电压，单位V，峰值标度。1f列名维持兼容；3f列明确带3f，不复用2f标签。run.json记录列与谐波的映射及相位设置，事件记录保存四通道结果与所选谐波。无效点仍将24列写NULL后继续。

此版是选择1f＋2f或1f＋3f，不是同时输出1f、2f、3f三组数据。3f模式在内部联合拟合DC、1f、2f、3f，把2f作为干扰项一并拟合，以降低短窗、非整周期时强2f泄漏到微弱3f的误差；该内部2f项不作为本模式的正式测量结果输出。增加拟合项不能消除源频率偏差、未知高次谐波、噪声或硬件失真，也不保证所有条件下更低的统计不确定度。

## 兼容与保留逻辑

旧方案缺少harmonic_order时补为2；缺少phase3_deg时补为−180°。旧方案已有的marker、1f、2f相位保持原值，缺失marker/2f时仍按历史0°迁移。保存后重新导入会保留谐波选择和独立相位。历史CSV不改写。

2182A/Delta驱动未改，Delta测量分支AST核对不变。环境无限等待、每点连续稳定时间、硬件过载状态检查、无效点NULL后继续、四通道同步采集均保留。新增采样率校验保证所选谐波低于Nyquist频率；实际采样率仍用于解调。

`python -m unittest discover -s tests -v`：109项，108通过、1项按原桌面条件跳过。记录在audit/regression_1.7.0.txt。

新增tests/test_harmonic_selection.py验证：

- 四通道不同的带符号弱3f信号，叠加强1f、强2f和DC，采用非整周期短窗；分别测试marker=0/90°、3f附加相位−180/23°。生产解调结果经硬件适配器、引擎、CSV、事件和显示映射逐项核对，24列误差均在1e−13 V测试容差内。这是解析输入的数值误差限，不是仪器精度。

- 旧方案导入、新方案JSON往返、独立相位保存、参数可见性、非法谐波、采样率限制、混合谐波运行拒绝。
- 数据面板3f曲线及指定通道显示、3f模拟运行路径。

前版本的1f/2f、环境等待和Delta回归测试继续通过。源码差异与2182A驱动哈希见audit/source_comparison_1.7.0.json。桌面实际交互和仪器实测不能由这些测试替代。

## 首次实机检查

先接线性标准电阻确认1f；3f应处于可重复的背景范围，并随激励检查源失真及自加热。使用已知相干1f＋3f注入验证三次谐波的幅值、相位及符号，再用于样品。测R–T中的微弱异常时，同时保留1f、3f的X/Y，比较不同电流与频率，不能仅凭3f异常就认定CDW。
