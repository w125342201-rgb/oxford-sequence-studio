## 0. 结论先行

1. **你描述的数据链路需要修正一处**：当前 4462 解调不是"FFT 找峰值"，而是**时域联合最小二乘拟合**（`fit_harmonics`），设计矩阵里**已经包含常数项**（DC）。因此：
   - 静态"本地热电势"（直流）在数学上**本来就不进入 1f 的 X/Y**，只进入 `dc_v`；
   - 换句话说，**静态热电势已经被现有实现排除了**，不是没处理。
2. **"把参考相位/窗口延迟 180° 再取两个值相减"在数学上等于 0 收益**：把参考或窗口转 180°，信号与任何 f 频率分量**一起变号**，`(X(+180°) − X(0))/2 = X`，只是把同一个数再算一遍（证明见 §2）。所以按这个思路实现，结果是"多花一倍时间、数值不变"。
3. **真正能"模拟 Delta"的唯一做法是让电流物理反向**（+I 与 −I 两次、参考不变、窗口不变），再取 `(X₊ − X₋)/2`。它抵消的是**所有不随电流翻转的 1f 分量**（放大器偏置、外部 1f 串扰、慢漂移）；对静态热电势没有额外作用（因为它本来就不在 1f 上）。
4. **这套硬件能否软件反流，取决于 6221 是否接受负幅值**：现有驱动明确拒绝负幅值，仓库里也没有 `SOUR:WAVE:PHAS` 这类相位命令。因此必须先做一次 5 分钟实机验证（§7）。若 6221 不接受，方案 A 无法实现，只能退到方案 B（零电流基线扣除）。

> 一句话：**你要的"开关"可以做，但"延迟 180°"不是它成立的方式；真正的开关必须对应"两次真实反流采集"。** 下面给出可行路径、数据影响和验证步骤。

## 1. 现状复核：4462 到底怎么出数

```
6221: SIN 电流，幅值 i_peak，marker(PMAR, line1) → PFI0 → 触发 4462 采集
4462: 每个通道一次有限采集 N 点（整数周期），Hann 加权
解调: [1, sin(hωt+h·m+φh), cos(...)] 联合最小二乘
输出: 每通道 1f 与所选谐波(2f/3f) 的 X / Y / 幅值，以及 dc_v、残差、条件数
电阻: 幅值 / i_peak
```

关键事实（`legacy/pxi4462/pxi4462_lockin.py::fit_harmonics`）：

- 设计矩阵第一列是常数项 → **DC 被显式拟合**，不进入 X1/Y1；
- 整数周期 + Hann 时，常数项与 sin/cos 严格正交，静态偏置泄漏为 0；
- 非整数周期时有极小泄漏，量级为窗函数旁瓣，而不是"偏置直接加进峰值"。

**因此"本地热电势 → 1f 峰值偏大"这个因果链在本实现里不成立。** 如果现场确实看到 1f 有非零偏置，来源更可能是：外部 1f 串扰/地环路、放大器在 f 处的残余、源自身的谐波失真、或采集窗与源频率不同步。

## 2. 三种"180°"的数学结论

设窗口起点 t=0，驱动电流 `I(t)=I·sin(ωt+φ0)`，样品电压 `V(t)=R·I·sin(ωt+φ0) + U(t) + V_dc`，其中 `U(t)` 是**与电流无关**的 1f 分量（串扰等）。

拟合给：`X = R·I·cos(φ0) + U_x`，`dc = V_dc`。

| 做法 | 第二次采集得到 | `(X₁ − X₂)/2` | 能否去偏置 |
|---|---|---|---|
| **① 参考相位 +180°**（同一段波形，φ→φ+180） | `−X₁` | `X₁` | **否**，恒等变换 |
| **② 采集窗口后移 180°**（PMAR+180，仍用原参考） | `−X₁` | `X₁` | **否**，与①等价 |
| **③ 真实电流反向**（I→−I，窗口与参考都不动） | `−R·I·cos(φ0) + U_x` | `R·I·cos(φ0)` | **是**，同时 `(X₁+X₂)/2 = U_x` |

> ②之所以等价于①：窗口后移半个周期后，所有频率为 f 的分量（信号与串扰）在固定参考下都变号，参考本身没变，所以整段一起翻转。**只有③能让"随电流变的分量"与"不随电流变的分量"分离。**

这也解释了 Delta 为什么有效：直流反流时，热电势不随电流变号，而 IR 变号，两者才能相减分离。AC 锁相里热电势是直流，本来就与 f 正交，所以"模拟 Delta"在 AC 下的实际收益是**去串扰/去漂移**，不是"去热电势"。

## 3. 两个可行方案

### 方案 A（首选）：真实反流 + 两个窗口平均

- 每次采集做两遍：`+I` 一次、`−I` 一次，**参考相位和窗口起点都不变**；
- 结果：`X = (X₊ − X₋)/2`、`Y = (Y₊ − Y₋)/2`、幅值 = hypot；偏置估计 `U = (X₊+X₋)/2` 只记录不导出；
- 电流怎么反：**唯一软件途径是 `SOUR:WAVE:AMPL −I`**（幅值取负）。6221 是否接受需实机验证（§7）。
- 优点：焦耳热在两半中相同（I²），温度状态稳定；真正抵消不随电流翻转的 1f 分量。
- 代价：单点时间约 ×2（两次采集 + 一次重配）。

### 方案 B（保底）：零电流基线扣除

- 每次采集：`I` 一次、`I=0`（幅值 0 或输出关）一次，`X = X(I) − X(0)`；
- 不需要反流，**一定能实现**；
- 缺点：两个半段的焦耳热不同（I² 与 0），温度/热电势在两次之间可能不同；对温度敏感实验不如 A。

### 方案 C（你最初的设想）：不做

参考/窗口 180° 翻转没有消偏效果（§2），实现它只会增加时间与复杂度，且会让"看起来有开关"但数据不变，属于必须避免的假功能。

## 4. 开关与数据设计（A 或 B 都要遵守）

### 4.1 开关粒度

建议：**每步骤一个布尔参数 `offset_cancel`（默认 False，仅 `mode='pxi'` 可用）**，但**同一次 PXI 运行内必须一致**（加入 `pxi_run_params` 的固定条件比较，与频率/谐波同级）。

理由：该开关改变同一列 `ai0_X_V` 的物理含义。若允许同一次运行混用，同一 CSV 里同名列一半带偏置、一半不带，分析必错。强制一致后：

- `run.json.pxi_contract.offset_cancel` 记录本次是哪种；
- 不需要新增 CSV 列，列数保持 **51**；
- 若以后确实需要混用，再单独加一列 `offset_cancel`（PXI 表 51→52），届时按 D 级变更处理。

### 4.2 数据含义（开关开启时）

| 列 | 含义 |
|---|---|
| `aiN_X_V` / `aiN_Y_V` / `aiN_V`（1f） | ±I 平均后的值（已去不随电流翻转的 1f 分量） |
| `aiN_2f_*` / `aiN_3f_*` | **仍取 +I 半段**，未做偏置消除（按你要求只处理 1f） |
| `current_a` | 仍为 +I 的设定值（不写负值） |
| `measurement_status` | 两半任一无效 → 该点整体 `invalid`/`NULL`（不静默只用一半） |

事件 `acquisition.data` 里额外保留两半的原始 X/Y、`U` 估计与两次窗口时间，便于追溯；不改变 CSV 列集合。

### 4.3 校验与兼容

- `SPECS['resistance']` 22 → 23 个参数，`upgrade_document`/`normalize_pxi_channels` 补默认 `False`；
- `validate`：`mode='delta'` 时该参数必须为 False（Delta 本身已是 ±I），否则报错；
- 旧方案载入后得到 `False`，行为与现在完全一致。

## 6. 测试计划（不需要硬件）

在 `SimBackend` 的 PXI 分支里注入：

```
真实信号 = R·I·sin(ωt)          随电流翻转
干扰项   = U0·sin(ωt + ψ)        不随电流翻转（模拟串扰/偏置）
```

断言：

1. 开关开启 → 输出 `X` 等于 `R·I·cosψ_signal`，误差 < 1e−9；偏置估计 ≈ U0；
2. 开关关闭 → 输出与当前实现**逐位一致**（用既有 51 列断言）；
3. 两半之一抛 `MeasurementError` → 该点 `NULL`，下一点继续；
4. 同一次运行内 `offset_cancel` 不一致 → 校验报错；
5. Delta 步骤带 `offset_cancel=True` → 校验报错；
6. 旧方案载入 → 参数补 `False`，行为不变。

## 7. 必须先做的实机验证（5 分钟，标准电阻）

**这是方案 A 的放行条件，未通过就只能选方案 B。**

1. 接标准电阻（如 100 Ω），电流 1 mA，13 Hz，确认 1f `X` 稳定。
2. 手动发 `SOUR:WAVE:AMPL -0.001`，随后读 `SOUR:WAVE:AMPL?` 与 `:SYST:ERR?`：
   - 若读回 `-0.001` 且无错误 → **支持负幅值**，方案 A 可行；
   - 若报错/被钳到 0 → 不支持，改方案 B（或改接线，加换向继电器）。
3. 若支持，继续验证：连续两次采集，`X₊` 与 `X₋` 应近似互为相反数（|X₊+X₋| ≪ |X₊−X₋|）。
4. 记录：幅值切换耗时、两半之间是否需要 `settle_s`、`verify_ac` 是否因负值报错。

> 若第 2 步不支持，我会把方案改为 B（零电流基线），并在规范里把"负幅值反流"登记为不可用（暂不写入 R 清单，因为属于硬件限制而非方案否决）。

## 10. 附：为什么"延迟 180°"直觉上很像、实际不成立

Delta 的反流之所以能去热电势，是因为**热电势是直流且与电流方向无关**，而 `I·R` 随电流变号；两个直流测量相减即可分离。

在 13 Hz 锁相中，热电势仍是直流，但它与 `sin(ωt)` 在一个周期内的积分为 0 —— 它根本不在 1f 的坐标里。把窗口或参考转 180°，等于把整个坐标系转 180°，信号和干扰一起转，差值为 0。**只有把电流真的反向，才相当于"信号换号、干扰不换号"。** 这就是本计划坚持"必须真反流"的原因。
