# Oxford Sequence Studio 1.7.3 修复说明

日期：2026-10-20。基于用户提供的 1.7.2 版本修订。

## 本次修复

| 原问题 | 修复后的行为 |
| --- | --- |
| 显式电极循环共用电压列，CSV 无身份信息 | 每行保存 route、columns、path、node_id；run.json 说明电压列按行路由解释。不同电极仍可共用 voltage_v，但已能可靠区分。 |
| 测完后环境读取失败或点击停止，已采电压可能丢失 | 先将采集结果写入并同步 events.jsonl，再读取环境。读取失败仍保存电压，环境值留空并标记 unavailable，不能当作温度/磁场有效点。 |
| 顺从电压允许低于仪器下限 | 配置和驱动均限制 0.1–105 V，不静默修改旧方案数值。 |
| AC 继承外部触发与电流量程设置 | 显式关闭波形外部启动、设置 BEST 量程及 ASCII 状态格式，并回读关键设置。 |
| Delta 可能读取上次完成事件 | 本次启动前清除旧状态事件，等待新的完成事件；中止事件报错。 |
| 设置未校验、顺从/错误未检查 | 回读源与 2182A 关键参数，检查错误队列及源状态。无法确认配置或源状态时停止运行并保留错误。 |
| 旋转位置校验失败后反复查询 | 首次校验失败后停止自动查询，人工确认运动停止后才能重新读取。 |
| 等待期间暂停/停止响应不足 | 环境等待和重试支持暂停并关闭输出；恢复时重新建立测量状态，稳定等待重新计时。Delta 固定等待和 DAQ 完成轮询支持停止。 |
| Delta 解析跳过坏字段、点数不真实 | 严格验证全部字段、有限值和点数；不再用最新单点替代 trace；actual_count 来自实际解析。异常不作为有效电压。 |
| Delta 实时框仍显示谐波 | Delta 隐藏谐波及 X/Y 选择，显示“Delta 电压”；修正文档默认除数说明，默认 divisor=1。 |

## 数据与兼容性

- CSV 在原字段基础上新增：route、columns、path、node_id、measurement_mode、measurement_status、environment_status、environment_error、acquisition_start_utc、acquisition_end_utc。
- 请按列名读取，不再按固定列号解析。4462 四通道双谐波的标准 CSV 为 41 列。
- “每点电极表”继续按电极分列；上述路由补充主要解决旧式显式电极循环的问题。
- 旧方案继续可载入；新增“保存原始四路波形”默认关闭。开启后在本次运行 waveforms 目录保存压缩 NPZ，包含 voltage_v、fs_hz、channels，详细事件中记录对应文件。
- 原始波形在过载判定前保存（前提是已取得完整有限数组），便于查明无效点原因；并非所有失败都能产生波形文件。
- 单次采集最多每通道 2,000,000 点，单点/单周期最多 600 秒；过长请求会明确拒绝，需调整采样率或时长。
- events.jsonl 增加 acquisition 持久化事件。若异常退出造成 CSV 未完整写入，可运行：

```bash
python audit/recover_points.py "运行目录/events.jsonl" "recovered.csv"
```

恢复工具输出逐次采集的长表，不覆盖原 CSV；它不是每点电极表的原样重建。没有可靠环境读数时留空。

## 验证结果

- unittest 共 143 项：142 通过，1 项因无显示环境跳过。记录：audit/regression_1.7.3.txt。
- 新增 18 项可靠性测试，覆盖路由身份、环境故障/停止保留数据、状态事件清除、异常数据、参数回读、暂停关源、旋转查询、DAQ 取消、波形保存及恢复工具。
- 独立解析波形与 200 次噪声试验通过，结果：audit/numeric_results_1.7.3.json。
- 测试使用模拟后端和明确的 SCPI 状态替身，不代表仪器联机验收。

## 使用与实机核对

解压到新目录，按原方式运行 start_windows.bat；载入原方案，核对仪器地址与配置后使用。旧历史输出、审查文件保留在包中，版本结论以本说明及带 1.7.3 文件为准。

本环境未连接 6221、2182A、4462 或旋转控制器。首次联机请用已知电阻核对 Delta 电压、4462 的幅值/相位以及暂停恢复和停止关源。单次驱动通信仍受 VISA/NI 超时限制，停止不等于任意阻塞调用都能瞬时中断；Delta 暂停在完整单点边界执行，不把半个 Delta 周期保存为有效数据。

真实链路的触发延迟、模拟滤波与线缆相移仍需实测校准，软件不虚构补偿值。6221 与 4462 无共用时钟带来的频差、弱信号幅值的非负噪声偏置仍是测量限制；分析带符号信号应使用经过相位校准的 X/Y。磁场、温度缺失的有效电压不可直接拼入 R–T 或 R–B 曲线。
