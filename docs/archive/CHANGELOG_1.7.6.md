# Oxford Sequence Studio 1.7.6 修改说明

日期：2026-10-22。依据 1.7.5 审查报告及逐项代码核查实施。

## 保留的规则

源顺从、过温、源状态错误、持续设置不符以及无法确认关源，仍停止整轮。普通电压超量程、无效数据、采集超时继续按 NULL 规则处理。不会自动扩大磁场容差、自动回零，或把目标值冒充实测值。

## 审查项目处理

| 项目 | 本版处理 |
|---|---|
| P0-1 源异常 | 按用户决定保留。开路导致源顺从时停止整轮。 |
| P0-2 磁场 no-op | 未达容差时写 field_not_started，保留进度进入无限等待；实际到位并稳定后继续。允许明确人工接受，不默认跳过。12 mT 仍仅用于现有 no-op 分类，不是软件强制的最小扫描步长。 |
| P1-1 通信异常 | 环境运动命令遇到 Oxford 通信/响应异常，转入观测等待，引擎不追加重发。驱动原有有界 FSET/RTOS 验证流程保留。非通信配置错误仍失败。旋转协议不重发、计时禁查询、人工静止复核规则保留。 |
| P1-2 设置回读 | 数值设置核验最多三次只读复核，间隔 0.1 s，支持停止；恢复日志保留全部回读。三次仍不符则源错误停整轮。不自动重配置、不重新 arm，不吞过温/顺从或错误队列。文本设置/错误队列校验仍严格执行。 |
| P1-3 人工环境接受 | 新增按钮，支持温度、磁场、气压及静止角度。请求绑定本次等待的唯一标识，工作线程重新回读；旧步骤请求不会作用到新步骤。停止优先。 |
| P1-4 环境异常 | 当前运行已控制过的轴必须有效；自动气压开启时 Probe 温度和压力必须有效；正在联动控温时 VTI 必须有效。其余记录通道的空值/非有限值/超量程可留空并标 partial。全部温压磁场通道缺失仍阻塞。传输断开/超时仍恢复重试，不冒充单通道缺失。Probe 无效时不发送热联动控制。 |
| P2-1 容差 | 保留默认 0.2 mT，需要根据实机确认。增加残差、已等时间、最近最多一分钟变化量显示，不自动放宽。 |
| P2-2 状态词 | 驱动和引擎共享归一函数：CLAMP/CLMP、TO SET/TOSET/RTOS、PAUSE/PAUS、TO ZERO/RTOZ；未知词保留原文用于诊断。 |
| P2-3 无效告警 | 实时显示累计和连续无效次数；连续达到 10 次时红色提示，每 10 次写告警事件；有效点清连续计数。只告警不改变普通无效点遍历规则。 |
| P2-4 布局测试 | 测试按控件树定位垂直分割窗，移除对已删除 content_split 属性的依赖。当前无显示环境，实绘测试仍未验收。 |
| P2-5 退出 | 正常关闭在成功关源且等待矩阵断电延时后断开继电器，再关闭连接；关源失败时不切继电器。强杀/电脑掉电无法靠退出代码保证关源，见下文。 |
| P3-1 计数 | acquisition_count 保持已采集计数；csv_row_count 在新逻辑行 write/flush/fsync 成功后增加。写盘失败仍失败退出，已写事件可用于恢复。 |
| P3-2 等待提示 | 同一励磁状态每 60 s 更新提示及剩余时间估计，不再只显示首次值。 |
| P3-3 等待事件 | 保留原有开始事件，新增 matrix_off_wait_end 和 matrix_on_wait_end。停止中断时没有伪造结束事件。 |
| P3-4 恢复表 | 电压列命名与主表统一，例如 ai0_V、ai0_2f_V、ai0_3f_X_V；仍输出一行一次采集的长表，不冒充逐电极宽表。 |
| P3-5/6 数据语义 | 明确 interval_s 是采集后的等待而非严格周期；电压 NULL、环境空白、未完成电极空白依靠状态列区分，保留既有含义。 |
| P3-7 Windows 启动 | 优先使用已安装的 py 启动器，否则使用 PATH 中的 python。程序报错后暂停，不自动第二次启动。缺少 Python 时显示提示。 |
| P3-8 空闲日志 | 相同刷新异常最多每分钟一条，错误变化或恢复立即提示；界面日志最多保留约 1000 行。运行事件文件继续保留完整日志。 |
| P3-9 绘图 | 保留最近 3000 次数据窗口、最高 4 Hz；慢绘图按耗时降低自动刷新频率，不删减保存数据。尚无真实显示性能基准。 |
| P3-10 说明 | 修正旋转自动查询描述：计时结束后单次回读，失败后等待人工静止复核。 |
| P3-11 历史源错误 | 原先已保存于 events.jsonl 的 acquisition.data.raw.pre_errors 和 point.raw.pre_errors；继续保留。成功返回前失败的路径不保证有完整 raw，按 failure/traceback 查找。 |
| P3-12 矩阵关闭 | 与 P2-5 一起处理，不无条件改底层 MatrixSwitch.close() 的行为。 |

## 人工接受当前环境值

1. 环境步骤正在等待时，点击左侧“接受当前环境值并继续…”。
2. 确认提示中的环境轴、目标和最近显示值。工作线程会重新读取实际值，以新回读作记录。
3. 磁场必须处于 HOLD/CLMP；正在励磁、回零或状态未知时拒绝接受。角度必须人工确认机械静止，且预计运动计时已结束，随后单次回读。
4. 接受成功后，后续数据标记 accepted_by_operator；同时有缺失记录通道时标记 partial_accepted_by_operator。environment_overrides 保存目标、接受时实际值、残差、时间和步骤。
5. 同一轴下一次环境设定清除该轴旧接受标记；其它轴标记继续保留，直到该轴重新设定或新一轮开始。逐电极表的 routeN_environment_overrides 各自保存。

人工接受仅跳过本次到位/稳定门槛，不修改控制器原目标，也不承诺后续环境不再变化。CSV 环境值始终记录采集后的实测值，接受时读数另外保存在 environment_overrides 中。暂停期间请求需恢复运行后由工作线程处理；缺少必要环境回读时仍等待恢复。

## 数据兼容性

- 序列 schema_version 仍为 7，旧方案无需手工迁移。
- data.csv 新增 environment_overrides，四通道 PXI 标准表由 50 列变为 51 列；逐电极表各 routeN_ 也新增对应字段。分析脚本应按列名读取。
- points 仍是 acquisition_count 的兼容别名，不是宽表行数。csv_row_count 表示首次完整落盘成功的逻辑行数量，可能含尚未测完所有电极的末行；之后更新同一行失败时，应结合运行失败状态和事件恢复。
- 电压 NULL 是测量无效；环境空白配合 partial/unavailable/stopped 等状态解释；尚未测量的电极列为空白。不要将空白或 NULL 当零。
- interval_s 是上次采集及记录完成后的等待，实际时间间隔请用 acquisition_start_utc/acquisition_end_utc。

## 退出与限值

请先用“停止运行”或正常关闭窗口，等待清理返回。任务管理器强制结束、主机掉电或通信中断可能让仍供电的 6221 保持输出，不能依赖进程退出自动关源。此时须在仪器端确认 OFF。程序不自动升温或退磁；旋转杆原协议没有停止指令。

电流与顺从电压仍由设备配置中的 max_current_a、compliance_v 和步骤 current_a 决定，运行前按样品确认。不得因本版恢复功能而放宽源异常停整轮规则。
